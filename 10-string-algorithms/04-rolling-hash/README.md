# Полиномиальное хеширование

[← К разделу](../README.md)

## Короткий отпечаток фрагмента

Полиномиальный хеш представляет строку числом по модулю M. Каждому символу сопоставляют число, выбирают основание B и последовательно умножают накопленный хеш на B, прибавляя новый код. Операции выполняются по модулю M.

Это позволяет быстро сравнивать отпечатки фрагментов, но не доказывает равенство строк: разные строки могут дать один остаток. Такое совпадение называется коллизией.

## Пример вычисления

Пусть a = 1, b = 2, c = 3, B = 10, M = 101 — маленькие числа только для иллюстрации. Для «abc» префиксные хеши H[0] = 0, H[1] = 1, H[2] = 12, H[3] = 22, потому что 123 по модулю 101 равно 22.

Хеш подстроки [l, r) равен H[r] − H[l]·B^(r − l) по модулю M с нормализацией. Для «bc», то есть [1, 3), получаем 22 − 1·100 = −78, остаток в диапазоне 0…100 равен 23. Это совпадает с прямым вычислением 2·10 + 3.

Вычитание удаляет вклад символов до l с теми же степенями, оставляя только нужный фрагмент. Заранее вычисленные степени B позволяют делать такой запрос за O(1).

## Сложность и достоверность

Подготовка хешей и степеней для длины n — O(n) времени и памяти. Один хеш фрагмента — O(1). Для сравнения фрагментов проверяйте также их длины. При совпадении хеша точное посимвольное сравнение даёт гарантированный результат, но добавляет время.

Два независимых хеша уменьшают вероятность случайной коллизии, но не превращают метод в безошибочный. Конкретная вероятность требует предположений о выборе параметров и данных; универсальное обещание «ошибок практически нет» не заменяет анализа.

В поиске Рабина — Карпа проверяются хеши всех окон длины m. Если каждое совпадение подтверждается сравнением, худшее время может быть O(nm), хотя фильтрация часто полезна. Для гарантированного линейного поиска подходят КМП или Z-алгоритм.

## Ошибки и практика

Промежуточные произведения могут переполниться до остатка. Отрицательное значение после вычитания требует нормализации. Учебные хеши не предназначены для хранения паролей.

**Практика.** При тех же параметрах хеш «ab» равен 12, «ba» — 21. Придумайте, почему модуль с конечным числом остатков неизбежно допускает коллизии среди неограниченного числа строк.
