# Суффиксные структуры данных

[← К разделу](../README.md)

## Подготовить текст к множеству запросов

Суффикс — фрагмент от некоторой позиции до конца. Суффиксные структуры организуют все такие окончания одного текста. Это полезно, когда текст постоянен, а запросов на поиск образца или повторов много. Начните с суффиксного массива; дерево и автомат рассматривайте как следующий уровень. В примерах есть наивное сжатое дерево для понимания рёбер и автомат; наивное построение дерева с копиями строк не имеет линейной гарантии эффективных алгоритмов.

## Пример: суффиксный массив

Текст «banana» имеет суффиксы по индексам: 0 → banana, 1 → anana, 2 → nana, 3 → ana, 4 → na, 5 → a. В лексикографическом порядке они идут так: a, ana, anana, banana, na, nana. Массив начальных индексов: 5, 3, 1, 0, 4, 2.

Все суффиксы с началом «ana» расположены рядом: индексы 3 и 1. Двоичным поиском можно найти границы этого блока. Если сравнение образца длины m с одним суффиксом стоит O(m), запрос имеет простую оценку O(m log n), а выдача k позиций требует ещё O(k).

## Общие начала соседей

LCP хранит длины общих префиксов соседних суффиксов. Для примера при соглашении LCP[0] = 0 получаем 0, 1, 3, 0, 0, 2. Максимум 3 показывает самую длинную повторяющуюся подстроку «ana»; перекрытия разрешены.

Наивная сортировка суффиксов с посимвольным сравнением может потребовать O(n² log n) времени. Метод удвоения ранжирует фрагменты длин 1, 2, 4, …: с обычной сортировкой пар он даёт O(n log² n), с линейной сортировкой рангов — O(n log n). Массив и ранги требуют O(n) памяти. После готового суффиксного массива LCP можно построить за O(n).

## Дерево и автомат

Суффиксное дерево — сжатое дерево суффиксов, где ребро может представлять целый фрагмент текста. Суффиксный автомат группирует подстроки по одинаковым возможным окончаниям в тексте. Оба имеют линейный размер и позволяют искать образец за O(m) при O(1) доступе к переходу, но сложнее в построении и доказательстве. Создание всех суффиксов как отдельных строк, напротив, занимает O(n²) символов.

**Практика.** Для «aba» суффиксный массив 2, 0, 1, LCP — 0, 1, 0. Повторяющаяся подстрока максимальной длины — «a». Объясните, почему суффикс начинается в конкретной позиции, а подстрока может закончиться раньше конца текста.

## Примеры на C#

| Файл | Что изучать |
|---|---|
| [Canonical.cs](examples/Canonical.cs) | Явные шаги алгоритма или устройство структуры; условия и затраты объяснены в комментариях. |
| [Modern.cs](examples/Modern.cs) | Современная запись, библиотечная замена или другой компромисс по времени и памяти. |
| [Applications.cs](examples/Applications.cs) | Небольшие практические сценарии, вызовы реализаций и ожидаемые результаты для самопроверки. |

Сначала получите ответ вручную, затем прочитайте каноничную версию и сравните с современной. В `Applications.Run` ожидаемый ответ указан первым аргументом проверки. Изменяйте вход и проверяйте, сохраняются ли условия применимости алгоритма.

Запуск из корня репозитория с установленным .NET 10 SDK:

```powershell
dotnet run --project examples/AlgoTraining.csproj -- 10-string-algorithms/05-suffix-structures
```

Устройство проекта, смысл современных конструкций и общие команды описаны в [инструкции запуска](../../examples/README.md). В методических темах код демонстрирует учебный сценарий; в алгоритмических — реализацию и её применение.
