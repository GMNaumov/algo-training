# Алгоритм Кнута — Морриса — Пратта

[← К разделу](../README.md)

## Не начинать сравнение заново

Алгоритм Кнута — Морриса — Пратта, КМП, при несовпадении использует уже известные совпадения. Его подготовка — префикс-функция π[i]: длина наибольшего собственного префикса образца, совпадающего с суффиксом его части до i включительно. Собственный означает короче всей рассматриваемой части.

Для «ababa» значения π равны 0, 0, 1, 2, 3. У всей строки общий префикс и суффикс «aba» длины 3. Это не повтор полного слова, а возможность сохранить часть совпадения после сдвига.

## Пример: сбой после длинного совпадения

Образец «ababac», текст начинается «abababac». Сначала совпали пять символов «ababa», затем вместо ожидаемой c пришла b. Перезапуск с нуля повторил бы много сравнений. По π[4] = 3 знаем, что конец совпавшей части «aba» уже является началом нового кандидата. Оставляем длину совпадения 3 и сравниваем ту же текущую b со следующим символом образца — b. Совпадение продолжается, и образец находится с позиции 2.

Состояние q означает: последние q обработанных символов текста совпадают с первыми q символами образца. При несовпадении возможное более короткое начало обязано быть границей уже совпавшей части. Цепочка π перечисляет именно такие границы; другие сдвиги не могут дать совпадение.

## Как получить префикс-функцию

Идём по образцу слева направо. Для очередного символа пробуем продлить границу предыдущей части. Если не получилось, переходим к её меньшей границе по уже вычисленной π, пока не найдём подходящую или не дойдём до нуля. Новые символы при этом не перечитываются с самого начала.

После полного вхождения для поиска перекрытий оставляем q = π[m − 1], а не обнуляем безусловно. Для «aaa» в «aaaa» это позволяет получить позиции 0 и 1.

## Затраты и практика

Подготовка O(m), поиск O(n), память O(m), без списка ответов. Длина совпадения увеличивается не более чем на единицу за прочитанный символ, поэтому число откатов суммарно линейно, несмотря на внутренний цикл.

Пустой образец обрабатывают до обычного алгоритма. Не смешивайте длину q с последним индексом совпавшей части.

**Практика.** Для «aaaa» префикс-функция 0, 1, 2, 3; для «abcd» — четыре нуля. Объясните, почему после полного совпадения «ababa» можно сохранить три буквы потенциального следующего вхождения.
