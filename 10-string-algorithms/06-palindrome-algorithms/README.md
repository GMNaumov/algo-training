# Алгоритмы для палиндромов

[← К разделу](../README.md)

## Симметрия вокруг центра

Палиндром равен своему развороту. Здесь сравнение точное, без удаления пробелов и изменения регистра. Подстрока должна быть непрерывной; палиндромная подпоследовательность — другая задача.

## Пример: расширение из центра

В «ababa» возьмём центральную букву a с индексом 2. Сравниваем соседние b и b, затем a и a; получаем весь палиндром длины 5. Каждый нечётный палиндром имеет центральный символ. Чётный, например «abba», имеет центр между двумя b, поэтому нужно проверять и промежутки.

Для каждого из O(n) центров расширяемся, пока границы внутри строки и символы равны. Любая палиндромная подстрока будет рассмотрена из своего центра. В худшем случае, например для одинаковых букв, время O(n²); дополнительная память O(1), если сохраняются только границы лучшего ответа. Явное копирование всех найденных подстрок меняет оценку.

## Радиусы и алгоритм Манакера

Манакер хранит радиусы палиндромов и переиспользует симметрию самого дальнего уже найденного палиндрома. Для нечётной длины удобно считать радиусом число символов от центра до края включительно: в «ababa» радиусы 1, 2, 3, 2, 1.

Если новый центр внутри известного палиндрома, берём зеркальный центр относительно старого. Его радиус даёт гарантированную начальную часть, но только до правой границы известного палиндрома. Всё за ней сравниваем явно. Когда расширение уходит дальше, обновляем центр и границу.

Зеркальная часть верна из-за симметрии большого палиндрома. Правую границу успешные дополнительные сравнения двигают только вперёд, поэтому суммарное время O(n), память O(n) для радиусов. Для чётных палиндромов нужен отдельный массив с центрами между символами либо преобразование строки с разделителями.

## ДП как альтернативный взгляд

Фрагмент [l, r] палиндромен, если крайние символы равны и внутренний фрагмент палиндромен; длины 1 и 2 — базы. Таблица по длине даёт O(n²) времени и памяти, полезна при множестве запросов о конкретных фрагментах.

**Практика.** В «abba» максимальная длина 4, в «abc» — 1, в пустой строке — 0. Для «aaa» всего шесть непустых палиндромных подстрок с учётом позиций. Объясните, почему поиск только нечётных центров пропускает «abba», и почему повторяющиеся буквы дают худший случай расширения из каждого центра.
