# Z-алгоритм

[← К разделу](../README.md)

## Насколько начало повторяется здесь

Z[i] — длина общего начала всей строки и её суффикса, начинающегося в i. Здесь задаём Z[0] = 0 по соглашению; иногда его считают длиной строки, поэтому это нужно уточнять. В отличие от префикс-функции, Z описывает совпадение, **начинающееся** в позиции i.

## Пример таблицы

Для строки «ababa» Z равно 0, 0, 3, 0, 1. В позиции 2 начинается «aba», совпадающее с первыми тремя буквами. В позиции 4 совпадает только первая a.

Если сравнивать с началом независимо для каждой позиции, строка из одинаковых букв даст O(n²). Линейный алгоритм поддерживает самый дальний уже известный блок [l, r), совпадающий с началом строки.

## Как переиспользуется блок

Если i лежит вне блока, начинаем обычное сравнение с префиксом. Если внутри, позиция i − l в префиксе соответствует i в блоке. Берём начальное значение как минимум из Z[i − l] и r − i. Внутри известной части оно гарантированно верно; за границей r сравнения ещё не проводились, поэтому возможное продолжение проверяется явно.

Для «aaaaa» позиция 1 создаёт блок до конца, получая длину 4. Для позиции 2 из известного блока сразу получаем 3, для позиции 3 — 2, для позиции 4 — 1. Длинные одинаковые фрагменты больше не пересравниваются полностью.

Каждое успешное дополнительное сравнение за пределами блока двигает правую границу вперёд; она не движется назад. Вместе с O(1) работой на позицию это даёт O(n) времени и O(n) памяти для массива.

## Поиск образца

Соедините образец, специальный разделитель и текст. Разделитель не должен встречаться ни в образце, ни в тексте. Если Z в позиции текстовой части не меньше длины образца, там начинается вхождение. Для «aba#ababa» получатся начала текста 0 и 2. Подготовка и поиск вместе занимают O(n + m) времени и памяти для объединённой последовательности и Z.

## Практика и ошибки

**Практика.** Для «aaaa» Z равен 0, 3, 2, 1. Для «abcd» все значения нулевые. Объясните, почему переносить Z[i − l] без ограничения r − i нельзя: известное совпадение могло бы выйти за ещё не проверенную границу. Для произвольного алфавита можно использовать отдельный служебный элемент, а не надеяться, что выбранный печатный символ отсутствует.
