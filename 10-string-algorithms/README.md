# Алгоритмы на строках

[← Главная](../README.md)

Строковые алгоритмы ищут совпадения и повторно используют уже проверенные части текста. Начните с обычного поиска подстроки, затем изучите КМП и Z-функцию; после них переходите к хешированию, суффиксам и палиндромам.

Нужны строки, массивы и сложность, для хешей — модульная арифметика. Здесь сравниваем выбранные единицы текста за O(1); в примерах используется небольшой алфавит без сложностей Unicode. Для реальных текстов правила регистра и нормализации задаются отдельно.

Например, поиск слова в журнале может повторно сравнивать одинаковые буквы. Итог раздела — понимание, какие проверки можно не повторять и какой ценой по памяти это достигается. Суффиксные структуры достаточно сначала освоить как обзор возможностей.
