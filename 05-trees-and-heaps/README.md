# Деревья и кучи

[← Главная](../README.md)

Дерево описывает иерархию: папки, категории товаров или подчинённость сотрудников. Разные ограничения на дерево дают разные возможности. Бинарное дерево ограничивает число детей, дерево поиска упорядочивает ключи, куча быстро выбирает минимум, префиксное дерево организует слова по общему началу.

Перед разделом нужны рекурсия, стек, очередь и сложность. Сначала научитесь рисовать обходы, затем сравнивайте гарантии поиска. Итог — вы различаете высоту и число узлов, не считаете любое дерево сбалансированным и выбираете структуру по нужной операции.

2. [Бинарные деревья поиска](02-binary-search-trees/README.md)
3. [Сбалансированные деревья поиска](03-balanced-search-trees/README.md)
4. [Кучи и приоритетные очереди](04-heaps-and-priority-queues/README.md)
