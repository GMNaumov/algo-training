# Префиксные деревья

[← К разделу](../README.md)

## Общие начала слов

Префиксное дерево, или trie, хранит строки по символам. Корень соответствует пустому префиксу, переход — следующему символу. Общие начала используют общий путь. Отдельная отметка показывает, что в узле заканчивается целое слово.

Это подходит для автодополнения и словаря команд. В отличие от обычного словаря по полному ключу, структура естественно отвечает на вопрос «какие слова начинаются с этого префикса?».

## Пример: подсказки в поиске

Добавим «кот», «код» и «ком». Из корня есть переход к, затем о, затем три ветки: т, д и м. Конечные узлы отмечены как слова. Поиск префикса «ко» проходит два перехода и находит начало поддерева подсказок.

Если добавить «котик», путь до «кот» сохраняется, от него идут и и к. Отметка конца «кот» остаётся: слово может одновременно быть началом другого слова. Простое наличие узла без отметки означало бы лишь существование префикса.

Для точного поиска идём по всем символам и проверяем конечную отметку. Для перечисления подсказок после префикса обходим его поддерево и восстанавливаем слова по пути.

## Сложность и память

Для слова длины L поиск и вставка занимают O(L), если поиск дочернего перехода O(1). Массив переходов по фиксированному алфавиту даёт прямой доступ, но может тратить много пустых ячеек. Словарь переходов экономит место на редких ветвях с ожидаемой стоимостью поиска.

При суммарной длине слов S число узлов O(S). Для массива переходов размера A память O(SA), для разреженных переходов — O(S) записей и узлов без учёта накладных расходов. Выдача всех подсказок стоит не только O(L), но и времени обхода и размера вывода.

## Границы и практика

Оговорите регистр, алфавит и пустое слово. При удалении слова нельзя безусловно стирать общий путь: другие слова могут его использовать. Сначала снимают конечную отметку, затем удаляют только ненужные ветви.

**Практика.** Для «дом», «дома», «док» найдите слова с префиксом «до»: все три. Удалите «дом» — «дома» должно сохраниться. Посчитайте переходы до «док»: три, независимо от числа других слов вне этого пути.
