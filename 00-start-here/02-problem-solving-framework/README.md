## Порядок рассуждения

Не начинайте с угадывания паттерна. Сначала переведите условие в точную задачу: какие данные даны, какой результат требуется, разрешено ли менять вход, возможны ли повторы и отсутствие ответа. Ограничения размера определяют, допустим ли полный перебор.

Рабочая последовательность:

1. Перескажите условие и придумайте маленький пример с ответом.
2. Постройте очевидное корректное решение, даже медленное.
3. Найдите повторную работу: что вычисляется заново, что можно запомнить или исключить?
4. Опишите состояние и правило следующего шага.
5. Объясните, почему решение не теряет правильный ответ.
6. Пройдите обычные и граничные примеры, оцените время и память.

## Пример: две покупки на заданную сумму

Есть цены 40, 60, 30, 70 и бюджет 100. Нужны **два разных товара** с точной суммой; достаточно одной пары. Перебор сравнивает каждый товар с последующими: 40 + 60 сразу даёт ответ. В общем случае пар примерно n²/2.

Ускорим поиск: для цены 70 нужен ранее встреченный товар за 30. Будем хранить множество уже просмотренных цен. Для 40 ищем 60 — ещё нет, запоминаем 40. Для 60 ищем 40 — найдено, ответ 40 и 60. Сначала проверяем дополнение, потом сохраняем текущую цену: так один товар не используется дважды.

Почему это работает? Для любой подходящей пары один товар встретится позже другого. При обработке позднего цена раннего уже сохранена. При подходящей хеш-таблице время ожидаемо O(n), память O(n); эти обозначения разбираются в [основах сложности](../../01-foundations/01-complexity-analysis/README.md).

## Проверка и типичные ошибки

Для бюджета 100 список из одного товара за 50 не имеет ответа, а два товара по 50 — имеет. Пустой список также не имеет пары. Если нужны номера товаров, одного множества цен недостаточно: нужно хранить связь цены с индексом. Если требуются все пары, это уже другая постановка.

**Практика.** Пройдите те же шаги для цен 20, 45, 55 и бюджета 90. Ответа нет. Затем замените 20 на 35: подходит 35 + 55. Объясните, какое состояние хранится после каждого товара и почему отсутствие пары в конце достоверно.
