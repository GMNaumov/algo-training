# С чего начать

[← Главная](../README.md)

Этот раздел помогает превратить чтение в навык. Предварительные знания алгоритмов не нужны: достаточно понимать переменные, условия и циклы. Сначала определите маршрут, затем освоите порядок рассуждения и систему повторений.

Например, задача о двух товарах с общей ценой 100 — это повод научиться уточнять условие, проверять пары, искать ускорение и объяснять результат. Цель первого этапа — уверенно выполнить эти действия вручную, даже если эффективное решение ещё не найдено.

После раздела у вас должны появиться журнал задач и привычка записывать: вход, требуемый результат, простой подход, проверку и вывод. Не измеряйте прогресс только числом просмотренных решений.

2. [Методика решения задач](02-problem-solving-framework/README.md)
3. [Практика и интервальное повторение](03-practice-and-spaced-repetition/README.md)

В конце каждой темы есть ссылки на каноничные и современные примеры C# и практические сценарии. Общие команды доступны в [инструкции запуска](../examples/README.md).
