# Дорожная карта обучения

[← К разделу](../README.md)

## Что предстоит освоить

Подготовка состоит из нескольких навыков: понимать условие, выбирать представление данных, строить алгоритм, обосновывать его и оценивать затраты. Знать название алгоритма полезно только тогда, когда вы можете применить его к новой задаче.

Идите по этапам:

1. Основы: индексы, сложность, ручная проверка. Результат — вы объясняете, почему один проход дешевле проверки всех пар.
2. Массивы, строки, хеш-таблицы, списки, стек и очередь. Результат — выбор структуры по нужным операциям.
3. Два указателя, окно, префиксы, сортировка, поиск и рекурсия. Результат — переход от перебора к более короткому решению с объяснением отброшенных вариантов.
4. Деревья, графы, динамическое программирование и жадные стратегии. Результат — работа с зависимостями и выбором между вариантами.
5. Строковые и продвинутые алгоритмы по необходимости, затем смешанная практика и пробные интервью.

Разделы справочника доступны на любом этапе. Сложные структуры не нужны для первых задач; если встречается незнакомый термин, вернитесь к связанной базовой теме.

## Пример учебной недели

Допустим, вы можете заниматься четыре раза по 40 минут. В первый день разберите поиск максимальной покупки среди цен 120, 70, 200. Во второй — самостоятельно найдите минимум и второй максимум, уточнив поведение при равенстве. В третий — восстановите подход без конспекта и разберите пустой список. В четвёртый — решите новую задачу о самом тёплом дне и сравните её с первой.

Так вы переносите идею, а не запоминаете конкретные числа. Для максимума достаточно помнить лучшую из уже просмотренных цен: после каждого шага это и есть максимум просмотренной части.

## Когда переходить дальше

Вы можете объяснить идею своими словами, пройти пример вручную, назвать крайние случаи и оценить число действий. Если ответ понятен только после чтения решения, тема требует повторения. Сроки индивидуальны: фиксированный календарь не заменяет эти критерии.

**Практика.** Запишите доступное время на неделю и выберите одну базовую тему. Сформулируйте проверяемый результат: «найти максимум вручную и объяснить один проход», а не «изучить массивы». После недели отметьте, что удалось сделать без подсказки.

## Примеры на C#

| Файл | Что изучать |
|---|---|
| [Canonical.cs](examples/Canonical.cs) | Явные шаги алгоритма или устройство структуры; условия и затраты объяснены в комментариях. |
| [Modern.cs](examples/Modern.cs) | Современная запись, библиотечная замена или другой компромисс по времени и памяти. |
| [Applications.cs](examples/Applications.cs) | Небольшие практические сценарии, вызовы реализаций и ожидаемые результаты для самопроверки. |

Сначала получите ответ вручную, затем прочитайте каноничную версию и сравните с современной. В `Applications.Run` ожидаемый ответ указан первым аргументом проверки. Изменяйте вход и проверяйте, сохраняются ли условия применимости алгоритма.

Запуск из корня репозитория с установленным .NET 10 SDK:

```powershell
dotnet run --project examples/AlgoTraining.csproj -- 00-start-here/01-learning-roadmap
```

Устройство проекта, смысл современных конструкций и общие команды описаны в [инструкции запуска](../../examples/README.md). В методических темах код демонстрирует учебный сценарий; в алгоритмических — реализацию и её применение.
