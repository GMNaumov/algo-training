# Практика и интервальное повторение

[← К разделу](../README.md)

## Как закреплять навык

Прочитанное решение легко кажется очевидным. Самостоятельное решение требует восстановить идею без текста перед глазами. Поэтому повторение — это попытка решить заново, а не повторное чтение.

В журнале храните условие своими словами, подход, причину его корректности, сложность, допущенную ошибку и дату следующей попытки. Отмечайте уровень помощи: самостоятельно, после подсказки, после полного разбора. Эти категории полезнее общей отметки «решено».

Начальный ритм можно выбрать такой: повторить на следующий день, через несколько дней, затем через одну-две недели. Это рабочая настройка, а не обязательная формула. Если идея не восстановилась, сократите интервал; если решение уверенное, смените контекст и увеличьте интервал.

## Пример одной записи

Задача: найти два чека с заданной общей суммой. Ошибка первой попытки: текущий чек добавлен в множество до проверки, поэтому чек на 50 использован дважды для суммы 100.

Следующая тренировка состоит из трёх частей:

1. На следующий день вручную проверить один чек на 50 и два разных чека по 50.
2. Через несколько дней решить похожую задачу с номерами заказов, где нужны индексы ответа.
3. Позже встретить задачу без названия паттерна и самому заметить поиск дополнения.

Критерий успеха — вы объясняете порядок проверки и добавления, а не только воспроизводите последовательность действий.

## Как работать с затруднением

Сначала выпишите, что именно неизвестно: смысл условия, простой подход или способ ускорения. Если долго нет продвижения, возьмите минимальную подсказку и продолжите. После полного решения закройте его, восстановите ход мысли и обязательно запланируйте новую попытку. Не нужно часами повторять одну и ту же безрезультатную мысль.

Чередуйте новые задачи, повторение ошибок и смешанные задачи. Постоянное решение только знакомого типа тренирует распознавание заголовка, но мало помогает выбирать подход самостоятельно.

**Практика.** Создайте вручную три записи: понятная тема, тема после подсказки и нерешённая задача. Для каждой назначьте следующую попытку и один конкретный вопрос самопроверки. Через неделю сравните не скорость чтения, а объём помощи, который потребовался снова.

## Примеры на C#

| Файл | Что изучать |
|---|---|
| [Canonical.cs](examples/Canonical.cs) | Явные шаги алгоритма или устройство структуры; условия и затраты объяснены в комментариях. |
| [Modern.cs](examples/Modern.cs) | Современная запись, библиотечная замена или другой компромисс по времени и памяти. |
| [Applications.cs](examples/Applications.cs) | Небольшие практические сценарии, вызовы реализаций и ожидаемые результаты для самопроверки. |

Сначала получите ответ вручную, затем прочитайте каноничную версию и сравните с современной. В `Applications.Run` ожидаемый ответ указан первым аргументом проверки. Изменяйте вход и проверяйте, сохраняются ли условия применимости алгоритма.

Запуск из корня репозитория с установленным .NET 10 SDK:

```powershell
dotnet run --project examples/AlgoTraining.csproj -- 00-start-here/03-practice-and-spaced-repetition
```

Устройство проекта, смысл современных конструкций и общие команды описаны в [инструкции запуска](../../examples/README.md). В методических темах код демонстрирует учебный сценарий; в алгоритмических — реализацию и её применение.
