## Базовый язык курса

Термины ниже — краткие напоминания. При первом знакомстве переходите к [основам](../../01-foundations/README.md), [структурам](../../02-linear-data-structures/README.md), [графам](../../06-graphs/README.md) и [ДП](../../07-dynamic-programming/README.md), где идеи разобраны по шагам.

| Термин | Значение |
|---|---|
| Алгоритм | точная последовательность действий, приводящая к решению |
| Вход | данные, с которыми решается конкретный экземпляр задачи |
| Ограничения | допустимые размеры, значения и свойства входа |
| Структура данных | организация хранения с определёнными операциями |
| Индекс | номер позиции; в массивах курса обычно от 0 |
| Диапазон [l, r) | позиции от l включительно до r исключительно |
| Инвариант | утверждение, сохраняемое каждым шагом алгоритма |
| Контрпример | допустимый вход, на котором утверждение или решение неверно |
| Сложность | зависимость затрат времени или памяти от размера входа |
| Худший случай | наибольшие затраты среди допустимых входов данного размера |
| Амортизированная оценка | стоимость операции через сумму затрат последовательности |
| Ожидаемая оценка | среднее по явно оговорённой случайности |
| Рекурсия | решение через обращения к тому же способу для подзадач |
| Базовый случай | часть рекурсивной задачи, решаемая без дальнейшего спуска |
| Стек | доступ к последнему добавленному элементу, LIFO |
| Очередь | извлечение в порядке поступления, FIFO |
| Дек | добавление и удаление с обоих концов |
| Ключ | признак, по которому идентифицируют и находят запись |
| Хеш | вычисленный отпечаток ключа для организации поиска |
| Коллизия | разные ключи получают одинаковый хеш или место хранения |
| Стабильная сортировка | сохраняет взаимный порядок равных ключей |
| Монотонность | изменение только в одном направлении; например, после первого «да» больше нет «нет» |
| Префикс | начальная часть последовательности |
| Суффикс | конечная часть последовательности |
| Подстрока | непрерывный фрагмент строки |
| Подпоследовательность | элементы в прежнем порядке с возможными пропусками |
| Палиндром | последовательность, равная своему развороту |
| Корень, лист | начало иерархии и узел без детей |
| Поддерево | узел вместе со всеми его потомками |
| Граф | объекты-вершины и связи-рёбра |
| Вес ребра | числовая стоимость одного перехода |
| Путь | последовательность переходов по рёбрам |
| Цикл | замкнутый путь; точные ограничения повторов зависят от определения |
| DAG | ориентированный граф без направленных циклов |
| Компонента связности | максимальная связная группа неориентированного графа |
| SCC | максимальная взаимно достижимая группа ориентированного графа |
| Релаксация | попытка улучшить расстояние через новое ребро |
| Остов | дерево, соединяющее все вершины исходного связного графа |
| Состояние ДП | достаточное описание подзадачи для вычисления её ответа |
| Переход ДП | правило получения состояния из уже решённых подзадач |
| Мемоизация | сохранение результатов вызовов, чтобы не вычислять повторно |
| Битовая маска | представление набора единичными битами числа |
| Жадный выбор | локальный выбор без последующего пересмотра |
| Остаточная сеть | доступные увеличения потока и возможности его отмены |

## Термины в одной задаче

В задаче «найти две покупки на сумму 100» цены — вход, число покупок — размер входа n, требование разных товаров — ограничение. Перебор пар — алгоритм. Словарь ранее просмотренных цен — структура данных. Сохранение только уже просмотренных товаров — часть инварианта. Единственный товар за 50 служит контрпримером решению, которое использует один товар дважды.

**Практика.** Для «abcde» назовите префикс «abc», суффикс «cde», подстроку «bcd» и подпоследовательность «ace». Затем сформулируйте инвариант поиска максимума: сохранённое значение равно максимуму уже просмотренной непустой части.
