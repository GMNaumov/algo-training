## Как выбирать дополнительный материал

Основной маршрут — этот курс на русском языке. Внешние материалы используйте для дополнительного объяснения и новых задач. Их язык, обозначения и примеры программирования могут отличаться от C#; сначала переносите идею на бумагу. Новичку не нужно одновременно проходить несколько полных курсов.

Ссылки проверены при наполнении материалов 2 ноября 2026 года. Доступные функции платформ, поддерживаемые среды и условия доступа могут меняться; проверяйте их перед началом работы. В этом этапе достаточно читать условия и разбирать небольшие входы вручную.

## Теория и официальная справка

- [MIT 6.006 — Introduction to Algorithms](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/): лекции, конспекты и задания на английском. Используйте после знакомства с основами, выбирая одну уже изучаемую тему. Это университетский материал, поэтому при затруднении возвращайтесь к простым примерам курса.
- [Microsoft Learn: выбор коллекции](https://learn.microsoft.com/en-us/dotnet/standard/collections/selecting-a-collection-class): справка для проверки назначения типов .NET. Полезна, когда идея решения понятна и нужно выбрать подходящую коллекцию для будущего кода.
- [Microsoft Learn: кодирование текста](https://learn.microsoft.com/en-us/dotnet/standard/base-types/character-encoding-introduction): поясняет различие между единицами UTF-16, кодовыми точками и видимыми символами. Открывайте при задачах с произвольным текстом.
- [MIT 6.851 — Advanced Data Structures](https://ocw.mit.edu/courses/6-851-advanced-data-structures-spring-2012/): дополнительный материал после базового курса; не обязательная предпосылка для начальных задач.
- [MIT 6.854 — Advanced Algorithms](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2005/): углублённые темы, включая потоки и рандомизацию. Подходит для дальнейшего изучения после соответствующих разделов.

## Новые задачи

- [LeetCode: каталог задач](https://leetcode.com/problemset/): источник задач для самостоятельного выбора и последующей интервью-практики. Сначала подбирайте условие по знакомой структуре, затем решайте смешанные задачи без подсказки о методе. Возможность запуска C# и доступность конкретного материала проверяйте на платформе.
- [CSES Problem Set](https://cses.fi/problemset/): набор задач с тематическими разделами, включая вводные задачи, сортировку, графы и ДП. Даже вводные задачи различаются по сложности: выбирайте по изученным идеям, а не только положению в списке.

Не копируйте полные чужие разборы в конспект. Записывайте собственное объяснение, ссылку на источник и то место, где понадобилась подсказка. После изучения решения возвращайтесь к задаче без открытого текста.

## Пример использования и практика

Вы изучили очередь и BFS. Возьмите задачу о кратчайшем пути в лабиринте, нарисуйте сетку 3 × 3, уточните разрешённые шаги и препятствия. Вручную заполните расстояния по слоям, затем придумайте недостижимый финиш. Только после своей попытки сравнивайте подход с разбором. Реализацию на C# оставьте следующему этапу проекта.

**Практика.** Выберите одну внешнюю задачу по уже изученной теме и запишите её собственными словами. Получите ответ для маленького примера без платформы, назовите инвариант и сложность. Если мешает новая терминология, сначала уточните её по [глоссарию](../04-glossary/README.md), а не переходите к готовому решению.
