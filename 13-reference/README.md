# Справочные материалы

[← Главная](../README.md)

Справочник помогает быстро восстановить обозначения и выбрать направление решения. Он не заменяет разбор темы: рядом с оценкой сложности важны её условия. Например, ожидаемое O(1) хеш-таблицы и гарантированное O(log n) дерева — разные обещания.

Используйте таблицы после самостоятельной попытки: сформулируйте нужные операции, найдите кандидатов и перейдите к полной теме. Шпаргалка C# сейчас содержит свойства типов и коллекций без кода. Ресурсы для практики выбирайте по текущему этапу, а не по количеству доступных задач.
