# algo-training

I don’t want my brain to dry out. Even though it really wants to.

Сборник материалов по алгоритмам и структурам данных: от базовых понятий до подготовки к алгоритмическим собеседованиям в ведущие технологические компании. Достаточно знать основы C#; опыт решения задач не требуется. Реализации используют C# 14 и .NET 10.

Алгоритм — точная последовательность действий для решения задачи. Структура данных — способ организовать информацию, чтобы нужные действия выполнялись удобно и быстро. Например, для истории отмены действий подходит стек, для очереди печати — очередь, для поиска заказа по номеру — хеш-таблица. Курс учит объяснять этот выбор и проверять его на конкретных данных.

## Как пользоваться курсом

Начните с [дорожной карты](00-start-here/01-learning-roadmap/README.md). Читайте одну тему, разбирайте пример на бумаге, затем выполняйте упражнения без подсказки. Ответ сам по себе недостаточен: объясняйте, почему шаги верны и как растут затраты при увеличении входа. Вернитесь к теме через несколько дней и решите похожую задачу с другими данными.

Сначала пройдите основы и линейные структуры, затем паттерны, поиск, деревья и графы. Динамическое программирование и жадные алгоритмы изучайте после уверенного владения перебором. Строковые и продвинутые темы — следующий круг, а справочник можно открывать по мере необходимости. Введение раздела указывает нужную подготовку; при ссылке вперёд можно прочитать только объяснение связанной идеи и вернуться.

Начинайте практику с ручной трассировки: записывайте вход, состояние после каждого шага и ожидаемый результат. Затем читайте и запускайте каноничные и современные реализации, сравнивайте их и меняйте входные данные. Например, перед поиском двух покупок на заданную сумму сначала перечислите все пары, а затем ищите способ не проверять лишние. Так оптимизация появляется из понятного решения.

## Примеры на C#

В каждой из 80 тем есть `examples/Canonical.cs`, `examples/Modern.cs` и `examples/Applications.cs`. В них находятся реализации с комментариями, практические сценарии и проверки ожидаемых результатов. Полная [инструкция запуска](examples/README.md) объясняет устройство общего проекта, современные возможности языка и ограничения учебных реализаций.

Установите .NET 10 SDK и выполните из корня:

```powershell
dotnet run --project examples/AlgoTraining.csproj -- --list
dotnet run --project examples/AlgoTraining.csproj -- 02-linear-data-structures/05-stacks
dotnet run --project examples/AlgoTraining.csproj -- --all
dotnet run --project examples/AlgoTraining.csproj -- --verify
```

## Текущий статус

Наполнены 14 разделов и 80 тем: теория на русском языке, жизненные примеры, разборы, оценки затрат, упражнения и 240 файлов примеров на C#. Общий консольный проект собирает все темы и запускает проверки без сторонних зависимостей.

Цель курса — научиться самостоятельно строить и объяснять решения. Прохождение материалов не гарантирует результат конкретного собеседования: готовность проверяется новыми задачами и пробными интервью. Правила развития материалов сохранены в [AGENTS.md](AGENTS.md).
