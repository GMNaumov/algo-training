# Жадные алгоритмы

[← Главная](../README.md)

Жадный алгоритм делает локально лучший выбор и не пересматривает его. Это может давать короткое и быстрое решение, но только при доказанном свойстве задачи. Для монет 1, 3, 4 выбор самой крупной монеты не минимизирует число монет для суммы 6.

Нужны сортировка, перебор и понимание оптимального ответа. Сначала изучите примеры стратегий, затем доказательства через обмен и сравнение префиксов. Итог — вы умеете проверять догадку маленькими контрпримерами и объяснять, почему конкретный выбор можно сделать безопасно.
