# Основы вычислительной геометрии

[← К разделу](../README.md)

## Геометрия через знаки и сравнения

Точка задаётся координатами (x, y), вектор — смещением. Для проверки положения часто достаточно арифметического предиката, без углов и квадратных корней. Например, для сравнения расстояний до точки сравнивают квадраты: dx² + dy².

## Пример: с какой стороны дороги точка

Пусть направленный участок идёт из A(0, 0) в B(4, 0), а склад C(2, 3). Вычислим ориентированное произведение векторов AB и AC:

(Bx − Ax)(Cy − Ay) − (By − Ay)(Cx − Ax).

Получаем 4·3 − 0·2 = 12. В обычной системе координат с осью y вверх положительный знак означает поворот против часовой стрелки, то есть C слева от A → B. Для D(2, −1) знак отрицательный, для E(6, 0) — нулевой: точки на одной прямой. На экране с y вниз визуальное направление обратное.

Нулевого произведения недостаточно, чтобы точка лежала на **отрезке**: E дальше B. Дополнительно координаты должны попадать в ограничивающий прямоугольник концов.

## Пересечение отрезков

Если концы каждого отрезка лежат строго по разные стороны прямой другого, есть внутреннее пересечение. Если какой-то знак нулевой, отдельно проверяют принадлежность точки отрезку. Это покрывает касание концами и коллинеарное наложение. Для общих точек пересечение ограничивающих диапазонов тоже обязательно.

Скалярное произведение dx₁·dx₂ + dy₁·dy₂ помогает проверять перпендикулярность: для ненулевых векторов ноль означает прямой угол. Площадь треугольника — половина модуля ориентированного произведения.

## Числа, затраты и практика

Каждый такой предикат использует O(1) арифметических операций и O(1) памяти при фиксированной ширине чисел. Но произведения координат могут переполнить тип, даже если сами координаты помещаются. Для вещественных данных ошибки округления способны менять знак около нуля; единая произвольная погрешность не решает все случаи. На первом этапе работайте с целыми координатами и проверяйте диапазоны.

**Практика.** Для A(0, 0), B(4, 0), C(0, 3) произведение 12, площадь 6. Отрезки (0,0)–(2,2) и (0,2)–(2,0) пересекаются в (1,1). Точка (3,3) лежит на их первой прямой, но вне первого отрезка.

Дополнительное объяснение точных предикатов и ошибок округления: [руководство CGAL, раздел Robustness](https://doc.cgal.org/latest/Kernel_23/index.html). Это справочный материал; для упражнений курса библиотека не требуется.

```powershell
dotnet run --project examples/AlgoTraining.csproj -- 09-bit-manipulation-and-math/06-computational-geometry-basics
```

Устройство проекта, смысл современных конструкций и общие команды описаны в [инструкции запуска](../../examples/README.md). В методических темах код демонстрирует учебный сценарий; в алгоритмических — реализацию и её применение.
