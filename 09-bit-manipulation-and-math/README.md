# Битовые операции и математика

[← Главная](../README.md)

Этот раздел даёт математические инструменты: компактное хранение наборов, делимость, остатки, подсчёт вариантов, случайный выбор и геометрические предикаты. Формулы вводятся через примеры; специальная математическая подготовка не нужна, но понадобятся аккуратность и проверка предположений.

Пример общей задачи: выбрать случайного победителя из потока заявок, не сохраняя весь список. Для этого важнее доказать равные вероятности, чем просто вызвать генератор случайных чисел.

Читайте темы по порядку либо возвращайтесь к ним из задач по маскам и строковым хешам. Итог — умение назвать условия формулы, оценить переполнение и отличить точную гарантию от вероятностной.
