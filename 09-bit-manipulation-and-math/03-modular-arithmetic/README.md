# Модульная арифметика

[← К разделу](../README.md)

## Работа с остатками

Числа сравнимы по модулю m, если имеют одинаковый остаток после деления на положительное m. Пример — часы: через 5 часов после 10 будет 3 на 12-часовом циферблате. Обычно выбирают представитель остатка от 0 до m − 1.

При сложении, вычитании и умножении можно сначала сократить операнды и затем снова взять остаток. Это полезно для больших счётчиков и количества вариантов. Но сравнивать исходные величины по остаткам нельзя: 3 и 10 дают один остаток по модулю 7, хотя не равны.

## Пример: огромный счётчик

Пусть нужно только число вариантов по модулю 7. Частичные количества 10 и 12 дают остатки 3 и 5. Сумма остатков 8 даёт 1 — тот же результат, что 22 по модулю 7. Если же варианты комбинируются независимо, произведение 10·12 = 120 даёт 1; произведение остатков 3·5 = 15 тоже даёт 1.

В C# остаток отрицательного числа может быть отрицательным: после вычитания требуется нормализация к диапазону 0…m − 1. Промежуточное умножение способно переполниться до взятия остатка; нужен достаточно широкий тип или безопасный способ умножения.

## Степень и деление

Быстрое возведение в степень использует двоичное разложение показателя. Для a¹³ нужны степени a¹, a², a⁴, a⁸; перемножаем a⁸·a⁴·a. Каждая следующая степень получается возведением предыдущей в квадрат с сокращением по модулю. Для неотрицательного показателя k время O(log(k + 1)) умножений, память O(1) в итеративной схеме при машинных числах.

Обычное деление остатков неверно. Вместо него используют обратный элемент b⁻¹: b·b⁻¹ даёт остаток 1. Он существует тогда и только тогда, когда НОД(b, m) = 1. По модулю 7 обратный к 3 равен 5, поскольку 3·5 = 15 даёт 1. По модулю 6 у 3 обратного нет.

Для простого p и b, не делящегося на p, обратный можно найти как b^(p − 2) по модулю p. Проверка предпосылок обязательна; для составного модуля эту формулу автоматически применять нельзя.

**Практика.** Найдите 2¹⁰ по модулю 7: 2. Нормализуйте −3 по модулю 5: 2. Объясните, почему остаток 0 у количества способов не доказывает отсутствие способов.

## Примеры на C#

| Файл | Что изучать |
|---|---|
| [Canonical.cs](examples/Canonical.cs) | Явные шаги алгоритма или устройство структуры; условия и затраты объяснены в комментариях. |
| [Modern.cs](examples/Modern.cs) | Современная запись, библиотечная замена или другой компромисс по времени и памяти. |

Сначала получите ответ вручную, затем прочитайте каноничную версию и сравните с современной. В `Applications.Run` ожидаемый ответ указан первым аргументом проверки. Изменяйте вход и проверяйте, сохраняются ли условия применимости алгоритма.

Запуск из корня репозитория с установленным .NET 10 SDK:

```powershell
dotnet run --project examples/AlgoTraining.csproj -- 09-bit-manipulation-and-math/03-modular-arithmetic
```

Устройство проекта, смысл современных конструкций и общие команды описаны в [инструкции запуска](../../examples/README.md). В методических темах код демонстрирует учебный сценарий; в алгоритмических — реализацию и её применение.
