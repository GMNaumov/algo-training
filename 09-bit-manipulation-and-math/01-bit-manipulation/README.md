# Битовые операции

[← К разделу](../README.md)

## Число как набор флагов

Двоичная запись использует цифры 0 и 1. Позиция i, считая справа от 0, имеет вес 2ⁱ. Например, 13 = 8 + 4 + 1 записывается 1101. Битовая маска интерпретирует каждый бит как наличие одного объекта.

Операции по каждой позиции: AND оставляет 1, только если обе позиции равны 1; OR — если хотя бы одна; XOR — если они различаются; NOT инвертирует биты. Сдвиг перемещает позиции. Для алгоритмических рассуждений сначала удобно работать с неотрицательными числами фиксированной ширины.

## Пример: доступ к функциям

Есть четыре функции с номерами 0…3. Набор 0101 разрешает функции 0 и 2. Чтобы проверить функцию 2, сравниваем набор с маской 0100 операцией AND: получаем 0100, значит разрешение есть. Добавление функции 1 через OR с 0010 даёт 0111. Переключение функции 0 через XOR с 0001 даёт 0110.

Для удаления разрешения используют AND с маской, где соответствующий бит 0, а остальные 1. Простое вычитание 2ⁱ без проверки наличия может испортить соседние биты.

## Полезные свойства

XOR числа с самим собой равен 0, с нулём — самому числу. Поэтому если все номера встречаются ровно дважды, кроме одного, XOR всех номеров оставит одиночный. Для 6, 3, 6 результат 3. Это не работает при произвольных частотах без дополнительных условий.

Для положительного x операция «x AND (x − 1)» снимает младший установленный бит. Повторение считает число единичных битов. Проверка степени двойки: x положительно, и после снятия единственного бита остаётся 0.

## Затраты и границы

Операции над машинным числом фиксированной ширины считаются O(1), память O(1). Перебор всех подмножеств n объектов требует 2ⁿ масок, а явный просмотр n битов каждой — O(n·2ⁿ). Для произвольно длинных чисел операция зависит от их длины.

В C# знаковые числа, ширина типа и правила сдвига требуют внимания: сдвиг за ожидаемую ширину не создаёт автоматически число большей разрядности. NOT меняет все биты типа, не только визуально записанные четыре.

**Практика.** Для 1010 и 1100 получите AND = 1000, OR = 1110, XOR = 0110. У числа 12 запись 1100, два установленных бита. Объясните, почему ноль не является степенью двойки.
