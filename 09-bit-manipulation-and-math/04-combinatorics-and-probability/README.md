# Комбинаторика и вероятность

[← К разделу](../README.md)

## Как считать варианты

Правило суммы: количества непересекающихся вариантов складываются. Правило произведения: если для каждого первого выбора доступно одинаковое число вторых, количества перемножаются. Порядок и возможность повторений нужно уточнять до формулы.

Перестановок n различных объектов — n! = 1·2·…·n. Выбрать k объектов из n без порядка можно C(n, k) = n! / (k!(n − k)!). По соглашению 0! = 1, а C(n, 0) = C(n, n) = 1.

## Пример: команда и роли

Из пяти разработчиков нужно выбрать двух на дежурство. Команд 5·4/2 = 10: при упорядоченном выборе каждая пара посчитана дважды. Если же один будет главным, а другой помощником, порядок ролей важен, вариантов 5·4 = 20.

Номер из трёх позиций с десятью допустимыми цифрами и разрешёнными повторами имеет 10³ вариантов, включая ведущий ноль. Если это трёхзначное число, первая цифра не может быть нулём: 9·10·10 = 900. Маленькое изменение условия меняет подсчёт.

## Вероятность и ожидание

При конечных равновероятных исходах вероятность события равна числу благоприятных исходов, делённому на общее число. Для случайного выбора пары из пяти человек вероятность включить Анну — 4/10: с ней можно выбрать любого из четырёх остальных.

Для независимых событий вероятность совместного наступления — произведение вероятностей. Без независимости нужно учитывать условную вероятность. Например, при выборе двух людей без возвращения выбор второго зависит от первого.

Математическое ожидание — среднее значение величины с учётом вероятностей. Если три независимых честных монеты дают по единице за орёл, ожидаемый выигрыш 3/2. Линейность ожидания позволяет складывать ожидания слагаемых даже без независимости, хотя произведение вероятностей так делать нельзя.

## Вычисления и практика

Факториалы быстро растут. Для точных C(n, k) можно использовать треугольник Паскаля: C(n, k) = C(n − 1, k − 1) + C(n − 1, k). Первые n строк стоят O(n²) времени; одна строка O(n) памяти. Обновление строки справа налево сохраняет предыдущие значения.

**Практика.** Из шести людей выбрать двоих: 15 способов. У двух честных монет вероятность ровно одного орла 1/2: благоприятны ОР и РО из четырёх исходов. Объясните, почему три возможных количества орлов — 0, 1 и 2 — не являются равновероятными: одному орлу соответствуют два исхода, остальным количествам по одному.
