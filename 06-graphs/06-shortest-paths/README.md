# Кратчайшие пути

[← К разделу](../README.md)

## Длина пути и свойства весов

Кратчайший путь минимизирует сумму весов рёбер. Выбор алгоритма зависит от весов и того, нужны ли расстояния из одной вершины или между всеми парами. Недостижимые вершины должны иметь отдельную отметку, а не расстояние 0.

## Пример: доставка

Дороги А → Б стоят 4, А → В — 1, В → Б — 2. Прямой путь в Б стоит 4, через В — 3. При релаксации проверяем, улучшает ли путь через текущую вершину известную оценку: расстояние до неё плюс вес ребра сравнивается с расстоянием до соседа.

Дейкстра сначала фиксирует А с расстоянием 0, получает оценки Б = 4, В = 1. Затем выбирает В как минимальную, улучшает Б до 3 и фиксирует Б. Неотрицательность весов гарантирует, что более дальняя ещё не выбранная вершина не сможет дать более короткий обходной путь к уже выбранной.

## Как выбрать алгоритм

| Условия | Метод | Время |
|---|---|---|
| Все рёбра одинаковой положительной стоимости | BFS | O(V + E) |
| Веса только 0 и 1 | 0–1 BFS с деком | O(V + E) |
| Неотрицательные веса | Дейкстра с бинарной кучей | O((V + E) log(V + 1)) для стандартной оценки простого графа |
| Возможны отрицательные веса | Беллман — Форд | O(VE) |
| Расстояния между всеми парами | Флойд — Уоршелл | O(V³) |
| Ориентированный граф без циклов | релаксации в топологическом порядке | O(V + E) |

В Дейкстре с повторным добавлением улучшенных оценок в очередь устаревшие записи пропускают; очередь может занимать O(E) памяти, а общая оценка записывается как O((V + E) log(V + E + 1)). При очереди с обновлением ключа — O(V) элементов.

Беллман — Форд повторяет релаксации до V − 1 раз: простой путь имеет не больше V − 1 рёбер. Улучшение на следующем проходе выявляет достижимый отрицательный цикл. Если через него можно пройти к цели, конечного минимума для неё нет. Флойд — Уоршелл хранит O(V²) расстояний; одноисточниковые методы — O(V) оценок сверх графа и очереди.

## Ошибки и практика

Не применяйте Дейкстру к отрицательным рёбрам. Не складывайте вес с условной «бесконечностью» без проверки. Родителей обновляйте при улучшении расстояния для восстановления маршрута.

**Практика.** В примере путь А → В → Б стоит 3. Если добавить Б → Г с весом 5, расстояние до Г — 8. Если веса не важны и считаются переходы, BFS выберет прямой А → Б за один шаг: это другая цель.
