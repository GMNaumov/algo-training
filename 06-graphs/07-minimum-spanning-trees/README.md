# Минимальные остовные деревья

[← К разделу](../README.md)

## Соединить все объекты дешевле

Остовное дерево неориентированного связного графа включает все V вершин, не содержит циклов и имеет V − 1 ребро. Минимальный остов, MST, минимизирует общую стоимость этих рёбер. Это модель прокладки кабеля между офисами, когда важна стоимость всей сети, а не длина отдельных маршрутов.

## Пример: четыре офиса

Есть рёбра А–Б: 1, Б–В: 2, А–В: 4, В–Г: 3, Б–Г: 5. Алгоритм Краскала сортирует их по весу. Берёт А–Б, затем Б–В, затем В–Г. Все офисы соединены, сумма 6. Ребро А–В не нужно: оно создало бы цикл внутри уже соединённой группы.

DSU помогает проверять, принадлежат ли концы разным компонентам. При принятии ребра группы объединяются. Для несвязного графа получится минимальный остовный лес — дерево для каждой компоненты; единого остова нет.

## Почему жадный выбор безопасен

Рассмотрим разрез — разделение вершин на две группы. Минимальное по весу ребро, пересекающее этот разрез, можно включить в некоторый минимальный остов. Если выбранный остов его не содержит, добавление создаст цикл. В цикле найдётся другое ребро через тот же разрез, не более лёгкое; замена не увеличит стоимость.

Краскал выбирает такое безопасное ребро между текущими компонентами. Алгоритм Прима делает другой выбор: растит одно дерево, каждый раз добавляя самое дешёвое ребро из него наружу. Оба опираются на свойство разреза.

## Оценки и границы

Краскал: O(E log(E + 1)) времени на сортировку плюс почти линейная работа DSU; память O(V + E) при хранении рёбер. Прим со списками и кучей имеет стандартную оценку O(E log V) для связного простого графа, с матрицей — O(V²). Память определяется представлением графа и очередью.

Отрицательные веса допустимы. При равных весах минимальных остовов может быть несколько. MST не гарантирует кратчайшие пути между вершинами; это другая оптимизация.

**Практика.** Для треугольника со стоимостями 2, 3, 10 остов имеет сумму 5. Для единственной вершины стоимость 0. Объясните, почему добавление самого дешёвого ребра, которое замыкает цикл, уже не нужно для соединения всех вершин.


Устройство проекта, смысл современных конструкций и общие команды описаны в [инструкции запуска](../../examples/README.md). В методических темах код демонстрирует учебный сценарий; в алгоритмических — реализацию и её применение.
