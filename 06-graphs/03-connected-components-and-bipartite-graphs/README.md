# Компоненты связности и двудольные графы

[← К разделу](../README.md)

## Группы достижимости

Компонента связности неориентированного графа — максимальная группа вершин, между любыми двумя из которых есть путь. Чтобы найти компоненты, запускайте DFS или BFS из каждой ещё не посещённой вершины; один запуск помечает одну компоненту.

## Пример: отдельные сети офисов

Связи А–Б, Б–В и Г–Д дают две компоненты: {А, Б, В} и {Г, Д}. Изолированная Е образует третью. Каждая вершина получает номер запуска, который её посетил. Если между двумя группами было бы ребро, обход прошёл бы по нему и объединил их, поэтому полученные группы максимальны.

Для ориентированных графов различают слабую и сильную связность. Обычный запуск обхода с учётом направления не делит их автоматически на компоненты сильной связности; это [отдельная тема](../../11-advanced-topics/05-strongly-connected-components/README.md).

## Два цвета без конфликта

Двудольный граф позволяет разделить вершины на две группы так, чтобы каждое ребро соединяло разные группы. Проверка: красим старт в первый цвет, соседей — во второй, их соседей — обратно в первый. Если ребро соединяет одинаковые цвета, разделение невозможно.

Например, квадрат А–Б–В–Г–А допускает группы {А, В} и {Б, Г}. Если добавить диагональ А–В, возникает треугольник, и два цвета не справляются. Вообще неориентированный граф двудолен тогда и только тогда, когда не содержит нечётного цикла: цвета вдоль цикла чередуются, а нечётная длина вынуждает конфликт.

Реальный пример — система несовместимостей: соседние задания должны попасть в разные из двух смен. Если граф двудолен, цвета дают допустимое распределение. Это работает именно для двух вариантов, а не решает общую раскраску в любое число цветов.

## Затраты и границы

Оба анализа занимают O(V + E) времени и O(V) дополнительной памяти на списках смежности. Проверять цвета нужно во всех компонентах, иначе можно пропустить конфликт в отдельной группе. Петля делает двудольность невозможной: вершина соседствует сама с собой.

**Практика.** Для цепочки из пяти вершин компонент одна, группы по цветам имеют размеры 3 и 2. Для трёх изолированных вершин компонент три, и любой выбор двух групп без внутренних рёбер допустим.

## Примеры на C#

| [Canonical.cs](examples/Canonical.cs) | Явные шаги алгоритма или устройство структуры; условия и затраты объяснены в комментариях. |

Сначала получите ответ вручную, затем прочитайте каноничную версию и сравните с современной. В `Applications.Run` ожидаемый ответ указан первым аргументом проверки. Изменяйте вход и проверяйте, сохраняются ли условия применимости алгоритма.

Запуск из корня репозитория с установленным .NET 10 SDK:

```powershell
dotnet run --project examples/AlgoTraining.csproj -- 06-graphs/03-connected-components-and-bipartite-graphs
```

Устройство проекта, смысл современных конструкций и общие команды описаны в [инструкции запуска](../../examples/README.md). В методических темах код демонстрирует учебный сценарий; в алгоритмических — реализацию и её применение.
