# Система непересекающихся множеств

[← К разделу](../README.md)

## Быстро объединять группы

Система непересекающихся множеств, DSU или Union-Find, хранит разбиение объектов на группы. Операция find возвращает представителя группы, union объединяет две группы. В начале каждый объект находится в собственной группе.

Внутри используется лес родительских ссылок; представитель — корень. Это служебные связи DSU, а не обязательно реальные рёбра исходной сети.

## Пример: подключение офисов

Есть офисы А, Б, В, Г. Добавляем связь А–Б: объединяем их группы. Добавляем В–Г: получаем вторую пару. Затем Б–В: представители различны, объединяем обе группы. Теперь А и Г связаны, хотя прямой линии между ними нет.

Если добавить А–Г, представители уже совпадают. В неориентированном графе это ребро соединяет вершины, между которыми уже был путь, то есть создаёт цикл. Само DSU путь не хранит.

Корректность опирается на инвариант: группы совпадают с компонентами связности всех добавленных рёбер. Новое ребро либо остаётся внутри компоненты, либо объединяет ровно две компоненты.

## Две оптимизации

При объединении по размеру меньшее дерево подвешивают к корню большего, чтобы не создавать длинные цепочки. Сжатие пути во время find направляет посещённые вершины ближе к корню. Совместно эти приёмы дают амортизированное O(α(V)) на операцию, где α — обратная функция Аккермана, растущая чрезвычайно медленно. Это почти константа для практических размеров, но формально не O(1).

Инициализация занимает O(V), хранение O(V). Без оптимизаций отдельный поиск корня может стать линейным. Счётчик компонент начинается с V и уменьшается только при успешном объединении разных групп.

## Ограничения и практика

Обычное DSU удобно при добавлении связей, но не поддерживает произвольное удаление ребра: одна группа после удаления может распасться. Оно также не решает ориентированную достижимость. Представитель группы может меняться, поэтому не используйте его как постоянный пользовательский идентификатор без отдельного правила.

**Практика.** Для пяти объектов выполните объединения 1–2, 2–3, 4–5, 1–3. Группы {1, 2, 3} и {4, 5}; компонент две. Последняя операция не уменьшает их число.
