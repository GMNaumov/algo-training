# Топологическая сортировка

[← К разделу](../README.md)

## Порядок с зависимостями

Топологическая сортировка — порядок вершин ориентированного графа, в котором для каждого ребра u → v вершина u находится раньше v. Ребро означает «u должно быть выполнено до v». Такой порядок существует только для ациклического ориентированного графа, DAG.

## Пример: подготовка отчёта

Нужно загрузить данные А, проверить их Б, построить график В и отправить отчёт Г. Зависимости: А → Б, Б → В, Б → Г, В → Г. Допустимый порядок А, Б, В, Г.

Алгоритм Кана считает входящую степень каждой вершины — число ещё не выполненных предпосылок. В очередь помещаются все вершины со степенью 0. Берём одну, записываем в результат, удаляем её исходящие зависимости, уменьшая степени соседей. Новые нулевые вершины добавляем в очередь.

В примере сначала готова А. После неё готова Б, затем В, затем Г. Если между независимыми задачами нет ребра, порядок между ними может быть любым.

## Почему это работает

Вершина с нулевой входящей степенью не зависит от оставшихся задач, поэтому её безопасно выполнить следующей. Удаление её рёбер точно отражает завершение одной предпосылки. Если обработано меньше V вершин, а очередь пуста, среди оставшихся есть цикл: у каждой остаётся хотя бы один предшественник, и, следуя им в конечном графе, мы повторим вершину.

Другой метод — DFS с состояниями «не начата», «в процессе», «завершена». Ребро в вершину «в процессе» обнаруживает цикл; обратный порядок завершения при отсутствии циклов даёт топологическую сортировку.

## Затраты и практика

Время O(V + E), дополнительная память O(V) сверх графа. Алгоритм не сортирует по числовому значению и не обязательно возвращает единственный порядок. Если нужен лексикографически минимальный порядок, выбор готовой вершины организуют приоритетной очередью, что увеличивает стоимость.

**Практика.** Для А → В и Б → В возможны А, Б, В и Б, А, В. Добавьте В → А: останется цикл А → В → А, полного порядка нет. Пустой граф без рёбер допускает любой порядок всех вершин, включая изолированные.
