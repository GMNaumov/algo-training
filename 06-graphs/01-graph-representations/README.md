# Представление графов

[← К разделу](../README.md)

## Вершины и рёбра

Граф состоит из вершин — объектов — и рёбер — связей. В ориентированном графе связь А → Б не означает обратную. В неориентированном ребро соединяет обе стороны. Вес задаёт цену, время или расстояние. Путь — последовательность переходов по рёбрам; цикл возвращается в исходную вершину.

## Пример: сеть складов

Есть склады А, Б, В, Г и дороги А–Б, А–В, Б–Г. В списке смежности храним соседей каждой вершины: А: Б, В; Б: А, Г; В: А; Г: Б. Неориентированное ребро представлено дважды, чтобы переход был доступен в обе стороны.

В матрице смежности строка и столбец соответствуют вершинам. Ячейка показывает наличие ребра или его вес. Для отсутствующего ребра нужен отдельный признак: нулевой вес может быть настоящим допустимым ребром.

Список рёбер хранит просто пары или тройки «откуда, куда, вес». Это удобно для перебора всех дорог и алгоритма Краскала, но без дополнительной подготовки не даёт быстрый список соседей.

## Сравнение затрат

| Представление | Память | Перебрать соседей v | Проверить конкретное ребро |
|---|---|---|---|
| Списки смежности | O(V + E) | O(deg(v)) | O(deg(v)) при линейном поиске |
| Матрица | O(V²) | O(V) | O(1) |
| Список рёбер | O(V + E) с учётом вершин | O(E) без индекса | O(E) |

deg(v) — число соседних рёбер вершины. Для ориентированного списка обычно имеются в виду исходящие рёбра. Разреженный граф имеет мало рёбер относительно V²; для него списки часто экономнее.

## Неявные графы и ошибки

На клетчатой карте вершинами служат свободные клетки, соседями — разрешённые шаги. Хранить все рёбра необязательно: их можно получать по координатам. Состояния головоломки тоже образуют граф переходов.

Явно сохраняйте изолированные вершины: по одному списку рёбер их существование не видно. Уточняйте допустимость петель и нескольких рёбер между одной парой. Для ориентированного графа не добавляйте обратное ребро автоматически.

**Практика.** Запишите представления для А → Б, Б → В, А → В и изолированной Г. Из В нельзя вернуться в А без дополнительных рёбер. Объясните, почему количество вершин остаётся 4, хотя Г не встречается в рёбрах.
