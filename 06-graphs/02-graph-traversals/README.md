# Обходы графов

[← К разделу](../README.md)

## Обойти всё достижимое

DFS, обход в глубину, сначала продолжает текущий путь и возвращается при отсутствии новых соседей. BFS, обход в ширину, сначала посещает вершины на расстоянии одного ребра, затем двух и далее. DFS использует стек, BFS — очередь.

В графе могут быть циклы, поэтому нужно отмечать посещённые вершины. Для BFS отметку ставят при добавлении в очередь: так одна вершина не попадает туда много раз через разных соседей.

## Пример: переходы между станциями

Есть рёбра А–Б, А–В, Б–Г, В–Г, Г–Д. Начинаем BFS из А. Сначала очередь содержит А. После её обработки в ней Б и В с расстоянием 1. Б открывает Г с расстоянием 2. При обработке В вершина Г уже отмечена, повторно её не добавляем. Затем Г открывает Д с расстоянием 3.

BFS даёт кратчайшие расстояния по числу рёбер, когда все переходы равноценны. Очередь обрабатывает слои в порядке неубывающего расстояния, поэтому более короткий путь к впервые открываемой вершине уже не может появиться позже.

Для восстановления маршрута сохраняйте родителя при первом обнаружении: Д ← Г ← Б ← А. Развернув цепочку, получаем А → Б → Г → Д. Другой столь же короткий путь через В тоже допустим.

## DFS и затраты

При выборе Б перед В DFS может пройти А, Б, Г, В, затем Д в зависимости от порядка соседей и возвратов. DFS удобен для анализа структуры, но первое найденное расстояние не обязано быть кратчайшим.

Для списков смежности оба обхода занимают O(V + E) времени и O(V) дополнительной памяти для отметок, очереди или стека. Для матрицы полный обход обычно O(V²). Запуск из одной вершины покрывает только достижимую часть; для всего графа запускайте обход из каждой ещё не посещённой вершины.

**Практика.** Добавьте изолированную Е: из А она недостижима. Затем добавьте ребро А–Д: BFS-расстояние до Д станет 1. Объясните, почему BFS без учёта весов неверен, если прямой переход занимает 100 минут, а три других — по одной минуте.

