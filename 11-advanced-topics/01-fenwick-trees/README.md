# Дерево Фенвика

[← К разделу](../README.md)

## Префиксы с изменениями

Дерево Фенвика хранит суммы специальных блоков массива. Оно поддерживает прибавление к одному элементу и сумму префикса за O(log n). Это удобно для отчётов о продажах, где прошлые значения регулярно исправляют: обычные префиксные суммы после каждого изменения пришлось бы пересчитывать.

Внутри используют индексы от 1. Ячейка tree[i] хранит блок длины lowbit(i), заканчивающийся в i. lowbit — значение младшего установленного бита: для 6 (110) это 2, для 8 (1000) — 8.

## Пример блоков и запроса

Значения по позициям 1…8: 2, 1, 3, 4, 2, 1, 5, 2. Тогда tree[4] хранит позиции 1…4 с суммой 10, tree[6] — позиции 5…6 с суммой 3, tree[7] — только позицию 7 со значением 5.

Для суммы первых семи позиций берём tree[7], затем уменьшаем индекс на lowbit: 7 → 6 → 4 → 0. Сумма 5 + 3 + 10 = 18. Выбранные блоки не пересекаются и точно покрывают префикс, поэтому результат верен.

При увеличении значения в позиции 5 на 3 обновляем содержащие её блоки: 5 → 6 → 8, каждый раз прибавляя lowbit к индексу. Остальные блоки не меняются. Новая сумма первых семи — 21.

## Возможности и оценки

Для полуинтервала исходного массива сумму получают разностью двух префиксов. Присваивание нового значения переводят в прибавление разницы между новым и старым. Запрос и точечное изменение — O(log n), хранение O(n). Построение отдельными прибавлениями O(n log n); существует линейное построение передачей готовых сумм в содержащие блоки.

Обычная структура для сумм не даёт автоматически произвольный минимум: у минимума нет операции вычитания. Для более общих запросов подходит дерево отрезков. Поиск позиции заданной накопленной суммы требует дополнительных условий, в частности неотрицательности частот для монотонности префиксов.

## Границы и практика

Индекс 0 не используют для обновления: его lowbit равен 0, движение остановится. Аккуратно переводите внешние индексы от 0 во внутренние от 1.

**Практика.** В примере сумма позиций 3…6 равна 10. После прибавления 3 в позиции 5 она станет 13. Выпишите блоки запроса префикса 6: позиции 5…6 и 1…4.
