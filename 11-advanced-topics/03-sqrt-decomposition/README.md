# Корневая декомпозиция

[← К разделу](../README.md)

## Промежуточный уровень между проходом и деревом

Корневая декомпозиция делит массив на блоки примерно по √n элементов и хранит сводку каждого блока. Запрос обрабатывает граничные неполные блоки поэлементно, а внутренние полные — по сводкам. Это часто проще дерева отрезков и достаточно быстро для умеренных ограничений.

## Пример: сумма по датам

Есть девять значений: 1, 2, 3 | 4, 5, 6 | 7, 8, 9. При размере блока 3 суммы блоков равны 6, 15, 24. Нужно получить сумму [1, 8), то есть от второго до восьмого элемента включительно.

Берём хвост первого блока 2 + 3, целиком второй блок 15, начало третьего 7 + 8. Итог 35. Каждый элемент диапазона входит ровно в одну из обработанных частей, поэтому ответ корректен.

Если значение 5 заменить на 10, второй блок увеличивается на разницу 5, его сумма становится 20. Для сумм точечное обновление можно выполнить за O(1), поскольку старое значение известно и агрегат обратим.

## Выбор размера и затраты

Для размера блока B запрос требует O(B + n/B): до двух неполных блоков и до n/B готовых сводок. Баланс достигается при B около √n, давая O(√n). Подготовка O(n), хранение исходных значений O(n) и дополнительных сводок O(n/B).

Для минимума присваивание может потребовать пересчёта целого блока за O(B): из старого минимума нельзя восстановить новый после удаления его значения. Для суммы этого не требуется. Значит стоимость обновления зависит от агрегата, а не только от названия метода.

Некоторые интервальные обновления поддерживаются метками блоков: полный блок меняется лениво, границы — поэлементно. Но правила хранения и последующего чтения необходимо описать отдельно.

## Когда выбирать и практика

Если нужны редкие запросы и почти нет обновлений, префиксы проще и быстрее для сумм. Если очень много сложных запросов, дерево отрезков может быть выгоднее. Декомпозиция полезна как понятный компромисс и основа других методов.

**Практика.** Для исходных девяти значений сумма [2, 7) равна 3 + 15 + 7 = 25. После замены 5 на 10 ответ станет 30. Проверьте запрос, целиком лежащий внутри одного блока: его нужно просмотреть один раз, не складывая дважды пересекающиеся края.
