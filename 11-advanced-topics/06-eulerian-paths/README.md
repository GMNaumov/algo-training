# Эйлеровы пути и циклы

[← К разделу](../README.md)

## Использовать каждое ребро один раз

Эйлеров путь проходит по каждому ребру ровно один раз; вершины могут повторяться. Если начало совпадает с концом, это эйлеров цикл. Не путайте его с гамильтоновым путём, который требует по одному посещению вершин.

Задача моделирует обход улиц или сборку последовательности из переходов. Если нужно повторять рёбра, чтобы соединить разрозненные участки, это уже другая оптимизация.

## Условия существования

В неориентированном графе все вершины с ненулевой степенью должны принадлежать одной компоненте. Для цикла все степени чётны; для незамкнутого пути ровно две вершины имеют нечётную степень, они будут концами.

Причина чётности: каждое промежуточное посещение использует одно ребро для входа и одно для выхода. У незамкнутого начала и конца остаётся по одному непарному ребру. Петля добавляет к неориентированной степени 2.

В ориентированном графе для цикла входящая и исходящая степени каждой вершины равны. Для открытого пути у старта исходящих на 1 больше, у конца входящих на 1 больше, у остальных степени равны. Дополнительно вершины с рёбрами должны быть связны при игнорировании направлений; вместе с указанными балансами этого достаточно.

## Пример и алгоритм Хиерхольцера

Есть треугольник А–Б–В–А и ребро А–Г. Нечётные вершины А и Г. Один эйлеров путь: Г → А → Б → В → А.

Алгоритм хранит стек текущего маршрута. Пока у верхней вершины есть неиспользованное ребро, помечаем ребро и переходим по нему. Если рёбер нет, снимаем вершину в выходной список. В конце разворачиваем список. Тупик добавляется в результат лишь тогда, когда все доступные продолжения исчерпаны; так отдельные циклы встраиваются в общий маршрут.

При списках смежности, уникальных номерах рёбер и продвижении по спискам время O(V + E), дополнительная память O(V + E). У неориентированного ребра две записи, но один номер: использование должно отмечать обе стороны.

## Проверка и практика

Начинайте с нечётной вершины для открытого неориентированного пути или с вершины нужного дисбаланса в ориентированном. Итог должен иметь E + 1 вершину и использовать каждое ребро ровно раз. Граф без рёбер требует договорённости о пустом или одноузловом маршруте.

**Практика.** В звезде с тремя листьями четыре нечётные вершины, эйлерова пути нет. В треугольнике все степени 2, цикл существует. Объясните, почему изолированная вершина не мешает обходу всех рёбер другой компоненты.
