# Компоненты сильной связности

[← К разделу](../README.md)

## Взаимная достижимость с направлением

Компонента сильной связности, SCC, — максимальная группа вершин ориентированного графа, где из каждой можно добраться до любой другой. Это полезно для анализа циклических зависимостей и групп страниц, между которыми возможен возврат по ссылкам.

Если каждую компоненту сжать в одну вершину, получится ациклический граф — конденсация. Цикл между разными компонентами сделал бы их взаимно достижимыми, следовательно они должны были бы быть одной компонентой.

## Пример

Рёбра А → Б, Б → А, Б → В, В → Г, Г → В образуют компоненты {А, Б} и {В, Г}. Из первой можно попасть во вторую, но вернуться нельзя. В конденсации только одно ребро между двумя группами.

## Алгоритм Косарайю

Сначала выполняем DFS исходного графа из всех ещё не посещённых вершин. Вершину записываем **при завершении**, после всех её потомков. Затем разворачиваем направление каждого ребра. Запускаем новые обходы в порядке убывания времени завершения первого прохода; каждый новый обход выделяет одну SCC.

Для примера при старте с А и посещении соседей по указанному порядку завершения могут быть Г, В, Б, А. Во втором проходе начинаем с А: в обратном графе получаем А и Б, но не уходим в В. Следующий новый старт выделяет В и Г.

Идея корректности: между компонентами образован DAG. В первом проходе времена завершения задают порядок, позволяющий во втором выбрать компоненту, из которой по обращённым рёбрам нельзя уйти в ещё не выделенные компоненты. Внутри неё все вершины взаимно достижимы, поэтому обход заберёт её целиком.

## Оценки и другой метод

Два DFS и разворот рёбер занимают O(V + E) времени. Дополнительная память O(V + E) для обратного графа, порядка, отметок и стека. Алгоритм Тарьяна находит SCC за один DFS с индексами открытия, low-link и стеком активных вершин, также за O(V + E); для первого освоения два прохода обычно проще проследить.

Не путайте стек активных вершин Тарьяна с любой посещённой вершиной. Не используйте порядок открытия вместо завершения в Косарайю.

**Практика.** В цепочке А → Б → В каждая вершина — отдельная SCC, хотя без направления граф связен. Добавьте В → А: все три окажутся в одной компоненте. Изолированная вершина тоже является SCC.
