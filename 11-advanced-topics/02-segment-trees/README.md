# Дерево отрезков

[← К разделу](../README.md)

## Разбить массив на интервалы

Дерево отрезков хранит агрегат каждого участка: сумму, минимум, максимум или другую сводку. Корень представляет весь массив, дети — две половины. Лист соответствует одному элементу. Ответ родителя получают объединением ответов детей.

Операция объединения должна быть ассоциативной: группировка соседних частей не меняет результат. Для суммы нейтральное значение 0, для минимума — условная бесконечность. Порядок частей сохраняют, если операция некоммутативна.

## Пример: продажи за диапазон

Массив 2, 1, 3, 4 разбивается на [0, 2) с суммой 3 и [2, 4) с суммой 7; корень хранит 10. Запрос [1, 4) берёт лист [1, 2) со значением 1 и целиком узел [2, 4) со значением 7. Ответ 8.

При замене значения с индексом 2 на 8 обновляется его лист, правый родитель до 12 и корень до 15. Остальные узлы остаются верными. Запрос разбивается на непересекающиеся полностью покрытые узлы, поэтому объединяет ровно нужные элементы.

## Массовые обновления и отложенные метки

При прибавлении x сразу ко всему покрытому узлом интервалу длины len его сумма увеличивается на x·len. Изменять каждый лист немедленно не нужно: в узле сохраняют отложенную метку. Перед спуском в детей метку передают им, чтобы их значения соответствовали уже учтённому обновлению.

Например, прибавление 5 ко всем четырём продажам увеличивает корень на 20. Если позже нужен один элемент, накопленное прибавление передаётся по пути к нему. Метки должны правильно сочетаться: прибавления складываются, а присваивание с прибавлением зависит от порядка операций.

## Затраты и ограничения

Построение и хранение — O(n). Запрос и точечное обновление — O(log n). Подходящие интервальные обновления с ленивым распространением также O(log n), но не произвольная операция поддерживается одной простой меткой.

Обязательно определите смысл узла, нейтральный результат вне запроса и способ объединения. Пустой вход требует отдельной обработки. Не смешивайте включённый конец с исключённым.

**Практика.** Для 2, 1, 3, 4 минимум [1, 4) равен 1. После замены индекса 1 на 6 минимум станет 3. Для суммы после прибавления 2 на [0, 2) весь массив имеет сумму 14. Объясните, почему для суммы метка умножается на длину, а для минимума достаточно прибавить 2 к агрегату.
