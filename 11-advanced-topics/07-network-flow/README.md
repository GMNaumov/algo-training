# Потоки в сетях

[← К разделу](../README.md)

## Ограниченные каналы и общий объём

Потоковая сеть — ориентированный граф с неотрицательными пропускными способностями, источником s и отличным от него стоком t. По каждому ребру проходит не больше его вместимости. В остальных вершинах входящий поток равен исходящему. Требуется максимизировать общий поток из s в t.

Модель подходит для ограниченной пропускной способности каналов или назначения исполнителей задачам. Поток не ищет кратчайший маршрут: несколько маршрутов могут работать одновременно.

## Остаточная сеть

Если по ребру вместимости c идёт f, вперёд можно добавить c − f. Обратное остаточное ребро ёмкости f позволяет отменить ранее отправленный поток и перенаправить его. Это возможность пересмотра решения, а не обязательно физический обратный канал.

Находим путь из s в t по положительным остаточным ёмкостям. Его узкое место — минимум ёмкостей вдоль пути. Увеличиваем поток на эту величину, обновляя прямые и обратные остатки.

## Пример: почему нужна отмена

Все каналы s → А, s → Б, А → Б, А → t, Б → t имеют вместимость 1. Если сначала отправить единицу по s → А → Б → t, прямого свободного пути может не остаться.

Но в остаточной сети есть путь s → Б → А → t: переход Б → А отменяет прежнюю единицу А → Б. После увеличения получаются два потока s → А → t и s → Б → t, общий объём 2. Без обратных рёбер алгоритм ошибочно остановился бы на 1.

## Оптимальность и оценки

Когда остаточного пути нет, выделим вершины, достижимые из s. Все прямые рёбра из этой группы наружу насыщены, а через обратное направление нет потока, который можно вернуть. Полученный разрез имеет вместимость, равную текущему потоку. Ни один поток не может превысить вместимость любого разреза, значит найден максимум. Это содержание теоремы о максимальном потоке и минимальном разрезе.

Метод Форда — Фалкерсона выбирает любой увеличивающий путь. При целых вместимостях он завершается; простая оценка O(EF), где F — значение максимального потока, не считая подготовки сети. Эдмондс — Карп выбирает путь BFS и даёт O(VE²), память O(V + E) для остаточной сети и поиска. Для произвольных вещественных вместимостей гарантии простого метода требуют отдельного анализа.

**Практика.** В примере разрез из одного s имеет ёмкость 2, поэтому больше двух единиц отправить нельзя. Уберите канал s → Б: максимум станет 1. Объясните, почему сохранение потока проверяется во всех промежуточных вершинах, но не требует нулевого баланса у источника и стока.
