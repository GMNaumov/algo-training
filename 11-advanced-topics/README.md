# Продвинутые темы

[← Главная](../README.md)

К этому разделу возвращайтесь после уверенной работы с базовыми структурами и графами. Первые три темы ускоряют запросы на изменяемых массивах, следующие — запросы по деревьям и анализ ориентированных графов, последние — использование всех рёбер и распределение ограниченных ресурсов.

Для запросов по массиву повторите префиксные суммы; для LCA — обход дерева и битовые операции; для сильной связности — DFS и топологический порядок; для потоков — пути и BFS. Например, сумма ежедневных продаж с постоянными исправлениями требует другой структуры, чем неизменяемый отчёт.

Это дополнительный круг подготовки. Не нужно знать потоки, чтобы решать первые задачи на массивы. Итог каждой темы — понимание модели и ручного выполнения; реализация сложных структур будет отдельным этапом.
