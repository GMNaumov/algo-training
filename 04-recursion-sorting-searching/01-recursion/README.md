# Рекурсия

[← К разделу](../README.md)

## Решение через меньшую копию задачи

Рекурсия — обращение к тому же способу решения для меньшего входа. Нужны базовый случай, который решается сразу, и шаг, приближающий к нему. У каждого вызова свои локальные данные; незавершённые вызовы хранятся в стеке.

## Пример: документы во вложенных папках

Нужно посчитать файлы во всём каталоге. Для папки считаем её собственные файлы, затем прибавляем ответы для каждой вложенной папки. Пустая папка без вложений даёт 0.

Пусть в корне 2 файла, в папке А — 3 файла, а в папке Б — 1 файл и вложенная пустая папка. Ответ для А — 3, для пустой папки — 0, для Б — 1 + 0 = 1, для корня — 2 + 3 + 1 = 6. После возврата из подзадачи родитель продолжает работу с сохранённым состоянием.

Корректность можно объяснить снизу вверх: если каждый вложенный каталог посчитан правильно и каждый файл относится ровно к одной папке, сумма даёт точный результат родителя. Для модели дерева переход всегда идёт глубже, а число папок конечно. В реальной файловой системе ссылки могут создавать циклы; тогда нужны правила посещения, как в графе.

## Время и память

Если каждый файл и каталог посещается один раз, время O(n), где n — их общее число. Дополнительный стек O(h), где h — максимальная глубина вложенности. В цепочке папок h может быть n. Рекурсивная запись не означает автоматически экспоненциальное время: важно число фактических подзадач и повторов.

## Ошибки и практика

Типичные ошибки: забытый базовый случай, вход не уменьшается, общий изменяемый результат случайно используется несколькими ветками, не учитывается глубина стека. Конечный алгоритм всё равно может исчерпать стек на глубоком входе; итеративный вариант с явным стеком позволяет управлять хранением состояний.

**Практика.** Для суммы первых n положительных чисел сформулируйте базу n = 0 → 0 и шаг «ответ для n − 1 плюс n». Для n = 4 проследите вызовы до 0 и возвраты 1, 3, 6, 10. Время и стек этой схемы O(n), хотя математическая формула позволяет получить ответ за O(1) арифметических операций.

## Примеры на C#

| Файл | Что изучать |

| [Canonical.cs](examples/Canonical.cs) | Явные шаги алгоритма или устройство структуры; условия и затраты объяснены в комментариях. |

Сначала получите ответ вручную, затем прочитайте каноничную версию и сравните с современной. В `Applications.Run` ожидаемый ответ указан первым аргументом проверки. Изменяйте вход и проверяйте, сохраняются ли условия применимости алгоритма.

Запуск из корня репозитория с установленным .NET 10 SDK:

```powershell
dotnet run --project examples/AlgoTraining.csproj -- 04-recursion-sorting-searching/01-recursion
```

Устройство проекта, смысл современных конструкций и общие команды описаны в [инструкции запуска](../../examples/README.md). В методических темах код демонстрирует учебный сценарий; в алгоритмических — реализацию и её применение.
