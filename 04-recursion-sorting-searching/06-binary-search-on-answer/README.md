# Бинарный поиск по ответу

[← К разделу](../README.md)

## Ищем границу допустимости

Иногда ответ — число, а не элемент массива. Если легко проверить «хватит ли значения x?», и при увеличении x ответ проверки меняется только один раз, можно двоично найти границу. Такая проверка называется предикатом допустимости.

Нужно доказать монотонность, выбрать диапазон, содержащий ответ, и определить, ищется первая истина или последняя ложь. Само наличие числового ответа ещё не делает бинарный поиск подходящим.

## Пример: грузоподъёмность доставки

Посылки весом 3, 2, 2, 4 нужно перевезти максимум за два дня, сохраняя порядок и не разделяя посылки. Ищем минимальную дневную грузоподъёмность C.

При C = 5 первый день вмещает 3 + 2, второй — 2, третий — 4: не подходит. При C = 6 первый день вмещает 3 + 2, второй — 2 + 4: подходит. Нижняя граница — максимальный вес 4, верхняя — общая сумма 11. Двоичные проверки постепенно находят первое подходящее значение 6.

Почему проверка заполняет день максимально? При фиксированном C перенос меньшего числа начальных посылок на текущий день не помогает сократить общее число дней: оставшийся хвост только длиннее. Значит жадный проход даёт минимально необходимое число дней при этой вместимости.

Монотонность проста: если вместимости C хватает, любая большая вместимость допускает тот же план. Последовательность ответов имеет вид «нет, …, нет, да, …, да».

## Затраты и ограничения

Одна проверка — O(n) времени и O(1) памяти. Для целочисленного диапазона ширины R общий поиск занимает O(n log(R + 1)) времени. Границы и суммы должны помещаться в выбранный числовой тип.

Если порядок посылок разрешено менять, прежняя проверка уже не обязательно отвечает на новую задачу. Для вещественного ответа нужны правило точности и условие остановки, а не бесконечное ожидание равенства границ.

**Практика.** Для весов 1, 2, 3 и двух дней минимальная вместимость 3: первый день 1 + 2, второй 3. Для одного дня нужна 6. Объясните отдельно корректность проверки и корректность двоичного поиска — это два разных доказательства.
