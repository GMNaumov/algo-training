# Рекурсия, сортировка и поиск

[← Главная](../README.md)

Этот раздел учит уменьшать задачу, перебирать варианты и использовать порядок. Рекурсия требует точного условия остановки, сортировка создаёт полезный порядок, бинарный поиск использует его для исключения половины вариантов.

Нужны массивы и анализ сложности. Пример общей связи: сначала каталог цен сортируют, затем находят границу доступного бюджета двоичным поиском. Но если требуется всего один максимум, сортировка избыточна — достаточно прохода.

После раздела вы умеете описать базовый случай рекурсии, восстановить состояние при переборе, выбрать сортировку по ограничениям и доказать монотонность перед бинарным поиском по ответу.
