# Динамическое программирование по битовым маскам

[← К разделу](../README.md)

## Подмножество как состояние

При небольшом числе объектов набор выбранных элементов можно кодировать битовой маской: бит i равен 1, если объект i включён. Для n объектов существует 2ⁿ масок. Перед темой разберите [битовые операции](../../09-bit-manipulation-and-math/01-bit-manipulation/README.md).

ДП по маскам полезно, когда будущее зависит от состава выбранного набора, но не от порядка, в котором он получен. Если порядок всё же влияет, нужно добавить информацию в состояние, например последний посещённый город.

## Пример: назначение задач сотрудникам

Есть два сотрудника и две задачи. Стоимости первого сотрудника: задача А — 3, Б — 1. Второго: А — 2, Б — 4. Каждому нужна ровно одна задача, каждая задача выдаётся один раз.

Пусть dp[mask] — минимальная стоимость назначения первых k сотрудников, где k — число установленных битов, а маска описывает занятые задачи. База для пустой маски 0. Следующему сотруднику пробуем каждую свободную задачу и улучшаем значение новой маски.

После первого сотрудника маска 01 стоит 3, маска 10 — 1. Полная маска 11 получается либо за 3 + 4 = 7, либо за 1 + 2 = 3. Ответ 3: первый делает Б, второй А.

Две истории с одинаковой маской назначили одинаковое число первых сотрудников и оставили одинаковые свободные задачи. Для дальнейшего решения важна только минимальная уже накопленная цена, поэтому остальные истории можно отбросить.

## Затраты и другой пример

Состояний 2ⁿ, переходов до n на состояние: O(n·2ⁿ) времени и O(2ⁿ) памяти. Для маршрута по городам нужно dp[mask, last]: один набор без последнего города недостаточен, потому что цена следующего перехода зависит от места отправления. Стандартный перебор переходов тогда требует O(n²·2ⁿ) времени и O(n·2ⁿ) памяти.

## Ограничения и практика

Экспонента быстро растёт: 2²⁰ — уже более миллиона масок. Учитывайте размер каждого состояния и ширину числового типа для маски. Нельзя объявлять метод эффективным только потому, что n выглядит небольшим. Невозможные назначения должны оставаться недостижимыми.

**Практика.** Для трёх задач маска 101 означает занятые задачи 0 и 2, следующему сотруднику доступна только задача 1. Число масок 8. Объясните, почему при произвольном выборе порядка сотрудников в состоянии пришлось бы дополнительно учитывать и их набор.
