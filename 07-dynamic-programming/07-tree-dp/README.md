# Динамическое программирование на деревьях

[← К разделу](../README.md)

## Объединение ответов детей

В дереве поддеревья разных детей не пересекаются. Если связь с родителем описывается небольшим состоянием, можно решить поддеревья независимо и объединить ответы. Для вычисления снизу вверх подходит обратный обход postorder.

## Пример: дежурные в иерархии

У сотрудников есть польза от участия в дежурстве, но начальник и непосредственный подчинённый не должны дежурить одновременно. Нужно максимизировать общую пользу. Для каждого узла v храним два ответа:

- take[v]: лучший результат поддерева, если v выбран;
- skip[v]: лучший результат поддерева, если v пропущен.

При выборе v его дети запрещены: берём пользу v плюс сумму skip детей. При пропуске v каждого ребёнка можно выбрать или пропустить: суммируем максимум его двух состояний.

У корня польза 5, у двух детей 4 и 3, других потомков нет. Для листьев take равны 4 и 3, skip равны 0. У корня take = 5 + 0 + 0 = 5, skip = 4 + 3 = 7. Ответ 7: выбрать обоих детей.

Почему дети независимы? В дереве между их поддеревьями нет дополнительных рёбер. Единственное ограничение, передаваемое сверху, — выбран ли родитель. Именно его и отражают два состояния. В произвольном графе поперечные связи разрушили бы такой переход.

## Порядок и затраты

Сначала считаем листья, затем родителей. Каждое ребро участвует в объединении один раз: O(n) времени, O(n) памяти для состояний и O(h) стека глубины. В неориентированном представлении при обходе пропускайте родителя, иначе немедленно вернётесь по тому же ребру.

Для восстановления выбранных сотрудников проходите сверху вниз: выбранный родитель запрещает ребёнка; иначе сравнивайте два его ответа. При равенстве возможны разные оптимальные наборы.

## Границы и практика

Если все пользы отрицательны, разрешение пустого набора даёт 0. При требовании выбрать хотя бы одного человека нужны дополнительные условия. Не переносите решение на иерархию с несколькими родителями без проверки, что вход действительно дерево.

**Практика.** В цепочке с пользами 5–1–6 оптимум 11: крайние вершины. Выпишите take и skip снизу вверх. Затем найдите размер каждого поддерева формулой «1 плюс сумма размеров детей» — это простейший пример ДП на дереве.
