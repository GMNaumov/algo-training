# Интервальное динамическое программирование

[← К разделу](../README.md)

## Ответ для непрерывного отрезка

Интервальное ДП хранит результат для фрагмента с границами l и r. Часто решение разбивается по месту последнего объединения. Маленькие интервалы должны быть вычислены раньше больших, поэтому таблицу заполняют по возрастанию длины.

## Пример: объединение соседних пачек

Есть пачки из 4, 2 и 3 документов. За раз разрешено объединить две соседние пачки; цена равна их суммарному размеру. Нужно минимизировать общую цену, пока не останется одна пачка.

Если сначала объединить 4 и 2, цена 6, затем объединить 6 и 3 за 9: итого 15. Если сначала 2 и 3, цена 5, затем 4 и 5 за 9: итого 14.

Обозначим dp[l, r] минимальную цену объединения пачек с l по r включительно. База dp[i, i] = 0: одну пачку объединять не нужно. Последнее объединение обязательно соединяет две соседние части [l, k] и [k + 1, r]. Перебираем k и берём минимум суммы стоимостей обеих частей, затем прибавляем общий размер [l, r]. Размер быстро получаем по префиксным суммам.

Для пары первых пачек ответ 6, для пары последних 5. Для всего интервала: минимум из 0 + 5 + 9 и 6 + 0 + 9, то есть 14. Каждое допустимое дерево объединений имеет последнее разделение k, поэтому переход рассматривает все варианты.

## Затраты и применение

Интервалов O(n²), в каждом до O(n) разделений: O(n³) времени, O(n²) памяти. Префиксы требуют ещё O(n). Без них повторный подсчёт суммы мог бы добавить лишнюю работу.

Другие примеры — расстановка скобок в цепочке матриц и выбор порядка операций на отрезке. В таких задачах переход зависит от смысла операции: нельзя автоматически прибавлять сумму элементов, как в задаче о пачках.

## Ошибки и практика

Не применяйте это решение, если разрешено объединять любые, а не только соседние пачки: задача меняется. Инициализируйте минимум невозможным большим значением, кроме базы; ноль может ошибочно выиграть у всех настоящих цен. При восстановлении сохраните место лучшего разделения.

**Практика.** Для пачек 1, 2, 3 оптимум 9: сначала 1 + 2 за 3, затем 3 + 3 за 6. Для одной пачки цена 0. Назовите порядок вычисления: длина 1, затем 2, затем 3.
