# Динамическое программирование на последовательностях

[← К разделу](../README.md)

## Порядок сохраняется, позиции можно пропускать

Подпоследовательность выбирает элементы с сохранением порядка, но без требования соседства. ДП на последовательностях часто хранит ответы для префиксов одной или двух строк. Обязательно различайте подпоследовательность и непрерывный фрагмент.

## Пример: общие действия пользователей

Две истории действий: «ABC» и «AC». Самая длинная общая подпоследовательность, LCS, — «AC», длина 2. Пусть L[i, j] — её длина для первых i и j символов.

Для пустого префикса ответ 0. Если последние символы совпадают, их можно добавить к общему ответу предыдущих префиксов: L[i − 1, j − 1] + 1. Если различаются, хотя бы один из этих последних символов не входит в общий ответ; берём максимум L[i − 1, j] и L[i, j − 1]. Таблица по строкам для «A», «AB», «ABC» против «A», «AC» даёт соответственно пары 1,1; 1,1; 1,2.

При восстановлении совпадающие символы добавляются в ответ, а при различии выбирается соседняя клетка с тем же оптимумом. Равенство вариантов может означать несколько правильных подпоследовательностей.

## Другие задачи того же семейства

Расстояние редактирования считает минимум вставок, удалений и замен. База для пустой строки — длина другой. Для последних символов сравнивают варианты удалить, вставить или сопоставить/заменить. При стоимости каждой операции 1 превращение «кот» в «кит» требует одной замены.

Для наибольшей строго возрастающей подпоследовательности, LIS, можно хранить лучшую длину, заканчивающуюся на позиции i. Проверяем все j < i с меньшим значением и продлеваем их ответы. Для 3, 1, 2, 5 длины по концам 1, 1, 2, 3, итог 3: 1, 2, 5.

## Сложность и практика

LCS и стандартное расстояние редактирования для длин n и m: O(nm) времени, O(nm) памяти; для одного числа возможны O(min(n, m)) памяти. Простой LIS: O(n²) времени и O(n) памяти. Улучшение LIS до O(n log n) использует бинарный поиск по минимальным возможным концам, но это отдельный следующий шаг.

**Практика.** Для «AB» и «BA» LCS имеет длину 1, вариантов два. Для 2, 2, 2 длина строго возрастающей подпоследовательности 1, а неубывающей — 3. Проверьте, какое сравнение требуется в каждой постановке.
