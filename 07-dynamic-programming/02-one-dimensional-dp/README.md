# Одномерное динамическое программирование

[← К разделу](../README.md)

## Состояние по одной позиции

В одномерном ДП состояние часто означает ответ для первых i элементов или для решения, заканчивающегося на позиции i. Эти смыслы различаются. Прежде чем записывать переход, произнесите точное определение: «лучший ответ на префиксе» и «лучший ответ с обязательным последним элементом» требуют разных формул.

## Пример: выбрать несоседние смены

Подработки по дням оплачиваются 4, 1, 1, 9. По условию нельзя работать два дня подряд. Обозначим best[i] максимальный доход среди первых i дней, разрешая не брать ни одной смены.

Последний день либо пропускается — тогда best[i − 1], либо берётся — тогда к оплате дня добавляется best[i − 2]. Получаем максимум этих двух вариантов. База: best[0] = 0, для первого дня best[1] = 4. Далее best[2] = 4, best[3] = 5, best[4] = 13. Оптимальны первый и четвёртый дни.

Разбор полный: любое допустимое решение либо содержит последний день, либо нет. В первом случае соседний предыдущий исключён, во втором остаётся прежний префикс. Более выгодное решение на соответствующем меньшем префиксе всегда улучшило бы и общий ответ, значит можно использовать его оптимум.

## Память и восстановление

На каждый день приходится O(1) работы, всего O(n). Таблица занимает O(n); если нужен только доход, достаточно двух предыдущих значений и O(1) памяти. Для восстановления дней можно хранить решения или пройти назад по таблице: если текущий ответ взят из предыдущего дня, пропускаем текущий, иначе выбираем его и переходим на два дня назад.

При равенстве оба продолжения оптимальны; договоритесь, какое возвращать. Если требуется хотя бы одна смена и все оплаты отрицательны, разрешение пустого набора в базе даст неверный ответ для этой новой постановки.

## Ещё одна форма

Максимальная сумма непрерывного фрагмента использует состояние «лучший фрагмент, заканчивающийся здесь»: либо начать заново с текущего числа, либо продлить предыдущий. Глобальный максимум берётся по всем концам. Это идея алгоритма Кадане; непрерывность отличает её от выбора несоседних дней.

**Практика.** Для оплат 2, 7, 9, 3, 1 ответ 12: дни 1, 3, 5. Для непрерывного фрагмента −3, 4, −1, 2, −5 максимум 5, фрагмент 4, −1, 2.

Сначала получите ответ вручную, затем прочитайте каноничную версию и сравните с современной. В `Applications.Run` ожидаемый ответ указан первым аргументом проверки. Изменяйте вход и проверяйте, сохраняются ли условия применимости алгоритма.

Запуск из корня репозитория с установленным .NET 10 SDK:

```powershell
dotnet run --project examples/AlgoTraining.csproj -- 07-dynamic-programming/02-one-dimensional-dp
```

Устройство проекта, смысл современных конструкций и общие команды описаны в [инструкции запуска](../../examples/README.md). В методических темах код демонстрирует учебный сценарий; в алгоритмических — реализацию и её применение.
