# Динамическое программирование

[← Главная](../README.md)

Динамическое программирование, ДП, сохраняет ответы на повторяющиеся подзадачи. Вместо запоминания формул учитесь выбирать состояние: какую информацию о прошлом нужно знать, чтобы правильно продолжать решение.

Потребуются рекурсия, перебор и анализ сложности. Одномерные задачи и сетки — первый круг, рюкзак и последовательности — второй, интервалы, деревья и маски — третий. Перед деревьями повторите обход postorder, перед масками — [битовые операции](../09-bit-manipulation-and-math/01-bit-manipulation/README.md).

Например, при планировании покупок мало знать уже потраченную сумму, если один товар нельзя брать дважды: может понадобиться знать и то, какие товары уже рассмотрены. Итог раздела — умение объяснить состояние, переход, базу и порядок расчёта, а затем оценить число состояний и стоимость одного перехода.
