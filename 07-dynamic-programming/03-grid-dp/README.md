# Динамическое программирование на сетках

[← К разделу](../README.md)

## Состояния в клетках

На сетке состояние обычно связывают с координатами строки r и столбца c. Если двигаться разрешено только вправо и вниз, каждая клетка зависит от верхней и левой. Зависимости не образуют циклов, поэтому таблицу удобно заполнять сверху вниз и слева направо.

## Пример: маршруты по складу

Есть сетка 3 × 3. Робот начинает в левом верхнем углу и идёт в правый нижний, только вправо или вниз. Центральная клетка заблокирована. В каждой доступной клетке храним число путей до неё.

В стартовой клетке 1 путь — пустая последовательность шагов. В первой строке и первом столбце до препятствий по одному пути. В центре 0. В клетке под правой верхней сумма 1 + 0 = 1; в клетке справа от левой нижней — 0 + 1 = 1. В финише 1 + 1 = 2. Два пути обходят препятствие по верхнему или нижнему краю.

Любой путь в клетку заканчивается либо шагом сверху, либо слева; группы не пересекаются. Поэтому сложение не пропускает и не дублирует маршруты. Если старт заблокирован, ответ 0, а не 1.

## Вариант: минимальная стоимость

Если в клетке задана цена входа, вместо суммы числа путей берут минимум стоимости верхнего и левого продолжения плюс цену текущей клетки. Недостижимое состояние помечают отдельно или бесконечностью с безопасной обработкой. Для старта уточняют, включается ли его цена.

Для сетки цен из двух строк 1, 3, 1 и 1, 5, 1, включая старт, таблица минимумов имеет строки 1, 4, 5 и 2, 7, 6. Ответ 6: вдоль верхнего ряда и вниз.

## Сложность и границы

Для R строк и C столбцов время O(RC), память O(RC). Если нужен только ответ, можно хранить одну строку O(C): значение сверху ещё старое, значение слева уже новое. Для восстановления пути удобнее полная таблица или отдельные предки.

При движении во всех четырёх направлениях возможны циклы: простое заполнение не решает задачу автоматически. Для кратчайших шагов тогда подходит BFS.

**Практика.** Для пустой от препятствий сетки 2 × 3 число путей равно 3. Для единственной доступной клетки — 1. Заблокируйте обе клетки, соседние со стартом: любой более дальний финиш становится недостижимым.
