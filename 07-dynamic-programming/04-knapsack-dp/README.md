# Задачи о рюкзаке

[← К разделу](../README.md)

## Выбор при ограниченном ресурсе

Задача о рюкзаке выбирает предметы с весами и полезностями при ограничении вместимости W. В варианте 0/1 каждый предмет берётся не более одного раза. В неограниченном варианте его можно брать повторно. Эти условия меняют порядок вычисления.

## Пример: оборудование курьера

Предметы имеют пары «вес, польза»: (2, 3), (3, 4), (4, 5). Вместимость 5. Обозначим best[i, c] максимальную пользу первых i предметов с общим весом **не больше** c.

Для очередного предмета есть два варианта: не брать — best[i − 1, c]; взять, если хватает места, — его польза плюс best[i − 1, c − вес]. Выбираем максимум. После первого предмета при вместимости 2…5 доступна польза 3. После второго при c = 5 получаем 3 + 4 = 7. Третий предмет даёт только 5, поэтому итог 7: первые два предмета.

Переход рассматривает все допустимые решения по наличию последнего предмета. Ссылка на предыдущую строку гарантирует, что тот же предмет не взят повторно.

## Сжатие таблицы

Полная таблица требует O(nW) времени и O(nW) памяти. Для одного значения можно оставить строку O(W), обновляя вместимости **по убыванию**: используемое меньшее c ещё относится к предыдущему набору предметов. При обходе вверх новый предмет мог бы использовать сам себя многократно — это уже неограниченный рюкзак.

Для точного заполнения веса базы иные: достижим только вес 0, остальные сначала невозможны. При оптимизации «не больше вместимости» пустой набор даёт 0 при любой c. Подмена этих смыслов — частая ошибка.

## Ограничения

Оценка зависит от числовой величины W, а не от числа цифр в её записи: алгоритм называют псевдополиномиальным. При гигантской вместимости он может быть непрактичен даже для небольшого n. Нулевые веса и неограниченное число предметов с положительной пользой могут сделать оптимум бесконечным; обычная постановка предполагает положительные веса.

**Практика.** Для того же набора при W = 4 ответ 5. В неограниченном варианте при W = 4 можно взять два предмета веса 2 и получить 6. Объясните на этом примере, почему направление обхода строки меняет задачу.
