# Паттерны решения алгоритмических задач

[← Главная](../README.md)

Паттерн — повторяющаяся схема рассуждения. Например, для поиска пары в отсортированных ценах можно двигаться с двух концов, а для суммы продаж за любые три дня — поддерживать окно. Паттерн применим только при выполнении его условий; название задачи их не гарантирует.

Нужны массивы, хеш-таблицы, стек и очередь. В задачах с отсортированным входом пока считайте порядок заданным; сами сортировки изучаются дальше. Top K использует [кучу](../05-trees-and-heaps/04-heaps-and-priority-queues/README.md): к этой теме допустимо вернуться после деревьев.

После раздела вы должны не только узнавать схему, но и объяснять, почему движение границ или удаление кандидата не теряет ответ.
