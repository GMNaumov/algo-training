# Top K и слияние K последовательностей

[← К разделу](../README.md)

## Выбирать только нужное

Top K — поиск k лучших элементов по выбранному признаку. Слияние K последовательностей — получение общего порядка из нескольких уже упорядоченных источников. Обе задачи удобно решать [кучей](../../05-trees-and-heaps/04-heaps-and-priority-queues/README.md), которая быстро возвращает минимальный или максимальный элемент.

## Пример: три крупнейших заказа

В потоке суммы 40, 10, 70, 30, 90, 60. Храним не более трёх значений в минимальной куче. После первых трёх это 10, 40, 70. Приходит 30: оно больше минимума 10, заменяем минимум. Приходит 90: заменяем 30. Приходит 60: заменяем 40. Остались 60, 70, 90.

Инвариант: после каждого шага куча содержит k крупнейших значений просмотренной части, либо все значения, если их пока меньше k. Значение не больше текущего минимума не улучшит набор. Вставка с удалением минимума сохраняет нужное число лучших кандидатов.

Для n элементов время O(n log(k + 1)), память O(k). Набор внутри кучи не отсортирован; вывод по порядку потребует O(k log k). Для k = 0 результат пуст, для k > n нужно уточнить договорённость.

## Пример: слияние журналов

Три сервера выдали отсортированные времена: 1, 7; 2, 5; 3, 4. Кладём в минимальную кучу первый элемент каждого журнала вместе с номером источника. Извлекаем 1, добавляем следующий из его источника — 7. Затем извлекаем 2, добавляем 5. Затем 3, добавляем 4. Итог: 1, 2, 3, 4, 5, 7.

В куче находится самый ранний ещё не использованный элемент каждого непустого источника. Любой следующий элемент того же источника не меньше его представителя, поэтому общий минимум обязательно среди представителей.

Для N элементов в k источниках время O(N log(k + 1)), дополнительная память O(k) без результата. Пустые источники пропускаются. При равных временах можно добавить номер источника как вторичный критерий, если нужен определённый порядок.

**Практика.** Найдите два максимума в 8, 1, 8, 4: с учётом повторов ответ 8 и 8. Затем слейте 1, 4 и 1, 3: ответ 1, 1, 3, 4. Объясните, почему нельзя просто добавить следующий элемент любого источника.
