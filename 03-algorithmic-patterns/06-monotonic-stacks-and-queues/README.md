# Монотонные стеки и очереди

[← К разделу](../README.md)

## Удаляем бесполезных кандидатов

Монотонная структура хранит элементы в неубывающем или невозрастающем порядке. Новый элемент может сделать старый бесполезным для всех будущих ответов; тогда старый удаляют. Ключевой вопрос — почему он уже никогда не понадобится.

## Пример стека: более тёплый день

Температуры 20, 18, 22, 21. Для каждого дня нужно число дней до следующей строго большей температуры. Храним индексы дней, для которых ответ ещё не найден; температуры в стеке невозрастают.

После 20 и 18 оба индекса в стеке. Приходит 22: для 18 это первый более тёплый день, ожидание 1; затем для 20 — ожидание 2. Удаляем оба и сохраняем индекс 22. День с 21 ответа предыдущему не даёт, поэтому остаётся в ожидании. В конце для 22 и 21 более тёплого дня нет. Результат: 2, 1, 0, 0, если 0 означает отсутствие.

Каждый снятый день получает ответ в первый подходящий момент: до него все просмотренные температуры были недостаточными. Для строгого сравнения равная температура не закрывает ожидание.

## Пример дека: максимум окна

Для значений 3, 1, 4, 2 и окна длины 3 храним индексы кандидатов с невозрастающими значениями. При поступлении 4 удаляем с хвоста 1 и 3: новый элемент больше и покинет окно позже, поэтому старые никогда не станут максимумом будущего окна, содержащего их. Максимумы окон равны 4 и 4.

Из головы удаляются индексы, вышедшие за левую границу. Максимум всегда в голове. Хранить одни значения неудобно: по индексу можно точно определить срок выхода, особенно при повторах.

## Сложность и ошибки

Каждый индекс добавляется один раз и удаляется не более одного раза с каждого пути обработки. Суммарное время O(n), память стека O(n), дека для окна O(k). Вложенные удаления не дают O(n²), поскольку удалённые индексы не возвращаются.

Ошибки: перепутать направление порядка, не удалить устаревший индекс, неверно обработать равные значения. Допустимо убирать равного более старого кандидата для максимума окна, но правила зависят от требуемого ответа.

**Практика.** Для температур 5, 5, 6 ожидания равны 2, 1, 0. Для окна 2 в 1, 3, 2, 5 максимумы 3, 3, 5. Нарисуйте содержимое структуры после каждого поступления.
