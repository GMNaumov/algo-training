# Связные списки

[← К разделу](../README.md)

## Последовательность через связи

Связный список состоит из узлов. Узел хранит значение и ссылку на следующий узел; в двусвязном списке есть ещё ссылка на предыдущий. Первый узел — голова, последний — хвост. В обычном линейном списке ссылка после хвоста отсутствует.

В отличие от массива, соседние узлы не обязаны лежать рядом в памяти. Чтобы найти десятый узел, обычно нужно пройти первые девять. Зато около уже известного узла можно изменить связи без сдвига всех последующих элементов.

## Пример: порядок треков

Плейлист имеет вид А → Б → В. Нужно добавить трек X после Б. Сначала новый узел X связываем с В, затем ссылку Б перенаправляем на X. Получается А → Б → X → В. Если сначала потерять ссылку на В, остаток списка станет недоступен.

Чтобы удалить X из односвязного списка, имея Б, направляем связь Б сразу на В. Если известен только X, для обычного удаления произвольного узла может потребоваться поиск предыдущего. В двусвязном списке сосед слева известен, но нужно согласованно изменить обе стороны.

Инвариант корректного линейного списка: проход от головы посещает все его узлы в нужном порядке и заканчивается после хвоста. Случайное направление ссылки назад может создать цикл.

## Цена операций

Поиск по значению или индексу — O(n). Вставка после известного узла — O(1). Удаление — O(1), если известны все нужные соседние ссылки. Добавление в хвост — O(1) при сохранённом хвосте. Сам список занимает O(n) памяти с накладными расходами на ссылки.

Разворот можно выполнить одним проходом, помня предыдущий, текущий и следующий узлы: O(n) времени, O(1) дополнительной памяти. Сначала сохраняют следующий узел, затем меняют связь текущего.

## Ошибки и практика

Отдельно рассматривайте пустой список, единственный узел, изменение головы и удаление хвоста. Список не становится быстрее массива для любого удаления: поиск места часто стоит O(n).

**Практика.** Нарисуйте А → Б → В и разверните связи по одной. Итог: В → Б → А. После каждого шага отмечайте сохранённую ссылку на необработанный остаток. Затем удалите все узлы по очереди, проверяя голову и хвост.
