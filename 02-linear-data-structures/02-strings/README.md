## Текст как последовательность

Строка хранит текст, но алгоритмически часто рассматривается как последовательность единиц выбранного алфавита. Сначала уточните, что считается символом: латинская буква, единица UTF-16 или видимый знак. Регистр, пробелы и знаки препинания тоже являются частью условия.

Подстрока — непрерывный фрагмент. Подпоследовательность сохраняет порядок, но может пропускать позиции. Для «котик» строка «оти» — подстрока, а «ки» — подпоследовательность, не подстрока.

## Пример: проверка названия на палиндром

Палиндром читается одинаково в обоих направлениях. Для «топот» сравним первый и последний знаки: т = т. Затем второй и предпоследний: о = о. Центральный п сравнивать не нужно. Все пары совпали — ответ положительный.

Почему этого достаточно? Каждая позиция имеет зеркальную пару. Проверка каждой пары один раз устанавливает равенство строки её развороту. Для «кот» первая же пара к и т не совпадает.

Время O(n), дополнительная память O(1), если доступ к выбранным единицам текста прямой. Создание перевёрнутой копии потребовало бы O(n) памяти. В C# строки неизменяемы: операции, создающие новый текст, нельзя считать бесплатными.

## Реальный контекст и ограничения

Поиск одинаковых названий клиентов может требовать игнорировать регистр и учитывать правила языка. Алгоритмическая задача с маленькими латинскими буквами проще: можно считать буквы по 26 ячейкам. Для произвольного текста такое предположение неверно. В .NET длина строки считает единицы UTF-16; один emoji может занимать несколько единиц, а видимый знак — состоять из нескольких кодовых точек.

Многократное присоединение к растущей строке может давать квадратичное копирование. Если задача требует составить большой текст, сначала продумайте накопление частей и единую сборку.

**Практика.** Проверьте «казак», «дом» и пустую строку. При обычном математическом соглашении ответы: да, нет, да. Отдельно сформулируйте правило для «А роза»: считать ли пробел и регистр? Без такого правила ответ неоднозначен.

Подробнее о единицах текста: [документация .NET](https://learn.microsoft.com/en-us/dotnet/standard/base-types/character-encoding-introduction).
