# Линейные структуры данных

[← Главная](../README.md)

Линейные структуры организуют данные в последовательность либо помогают быстро находить элементы в ней. Сравнивайте их на одном сценарии: список покупок, поиск товара по артикулу, история действий и очередь клиентов требуют разных операций.

Сначала освойте массивы и строки, затем хеш-таблицы, связные списки, стек и очередь. Потребуется понимание индекса и оценок O(1), O(n) из основ. Итог: вы можете нарисовать структуру, выполнить её операции вручную и объяснить цену поиска, вставки и удаления.

2. [Строки](02-strings/README.md)
3. [Хеш-таблицы](03-hash-tables/README.md)
4. [Связные списки](04-linked-lists/README.md)
5. [Стеки](05-stacks/README.md)
6. [Очереди и деки](06-queues-and-deques/README.md)

В конце каждой темы есть ссылки на каноничные и современные примеры C# и практические сценарии. Общие команды доступны в [инструкции запуска](../examples/README.md).
