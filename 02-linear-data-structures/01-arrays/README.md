# Массивы

[← К разделу](../README.md)

## Идея и применение

Массив — последовательность ячеек с доступом по индексу. Для n элементов индексы идут от 0 до n − 1. Как у шкафчиков с номерами, нужная позиция известна заранее: не требуется открывать все предыдущие ячейки.

Размер обычного массива фиксирован. Динамический массив скрывает выделение большего хранилища и перенос элементов, когда место заканчивается. Это сохраняет быстрый доступ по индексу, но делает некоторые добавления дорогими.

## Пример: продажи по дням

Продажи за четыре дня: 5, 8, 3, 6. Значение третьего дня находится по индексу 2 и равно 3. Чтобы найти лучший день, идём слева направо: максимум сначала 5, затем 8, после 3 и 6 он остаётся 8. После каждого шага сохранён максимум уже просмотренной части — это объясняет корректность одного прохода.

Предположим, нужно вставить продажи пропущенного дня между 8 и 3. Если место зарезервировано, сначала сдвигаем 6 вправо, затем 3 вправо, после этого записываем новое значение. Сдвиг справа налево не затирает ещё не перенесённые данные. Если свободного места нет, требуется новый массив.

## Затраты

Доступ и замена по индексу — O(1). Поиск значения без дополнительной информации — O(n). Вставка и удаление в середине с сохранением порядка — O(n) из-за сдвига. Добавление в динамический массив — амортизированно O(1), отдельное расширение — O(n).

Хранение — O(n). Поиск максимума использует O(1) дополнительной памяти. Копия массива требует O(n). Если порядок не нужен, удаление можно выполнить заменой удаляемого элемента последним и сокращением логической длины: O(1) при известном индексе.

## Границы и практика

Не путайте индекс 0 с первым значением. Пустой массив не имеет максимума без отдельно оговорённого результата. Не обращайтесь к индексу n. Перед изменением входа уточняйте, нужно ли сохранять исходные данные.

**Практика.** Вставьте 4 между 8 и 3: получится 5, 8, 4, 3, 6. Затем удалите 8 с сохранением порядка. Ответ: 5, 4, 3, 6. Посчитайте сдвиги и объясните, почему удаление первого элемента обычно дороже удаления последнего.
