# Очереди и деки

[← К разделу](../README.md)

## Порядок обслуживания

Очередь добавляет элементы в хвост и извлекает из головы. FIFO означает «первым пришёл — первым вышел». Это подходит для очереди печати и обработки заявок без приоритетов. Дек, или двусторонняя очередь, разрешает добавление и удаление с обоих концов.

Обычную очередь можно хранить в кольцевом буфере: индексы головы и хвоста переходят с конца массива в начало. Тогда извлечение не требует сдвигать все элементы. Нужно отдельно различать пустой и заполненный буфер, например по числу элементов.

## Пример: очередь принтера

Пришли документы А, Б, В. Голова у А. Принтер извлекает А, затем приходит Г: очередь Б, В, Г. Следующим печатается Б. Добавление Г не меняет порядок уже ожидающих документов.

Инвариант: в очереди остаются все ещё не обработанные заявки в порядке их поступления. Извлечение удаляет самую раннюю, а добавление ставит новую после всех старых. Это объясняет справедливый порядок, но не учитывает разные срочности: для срочности нужна очередь с приоритетом.

## Дек и очередь из стеков

В деке можно хранить последние действия с возможностью убирать данные с обоих концов. Позже [монотонная очередь](../../03-algorithmic-patterns/06-monotonic-stacks-and-queues/README.md) использует это для максимума скользящего окна.

Очередь также строится из двух стеков. Новые элементы попадают во входной стек. Если выходной пуст, весь входной переносится в него: порядок разворачивается, и самый старый оказывается сверху. Каждый элемент переносится не более одного раза.

## Сложность и границы

При подходящей реализации операции на концах — O(1), расширение массива даёт амортизированное O(1) добавление. Очередь из двух стеков также имеет амортизированное O(1) на операцию, хотя один перенос может занять O(n). Хранение — O(n). Поиск произвольного элемента обычно O(n).

Не извлекайте из пустой очереди без оговорённого поведения. Реализация удалением первого элемента обычного массива со сдвигом стоит O(n), даже если названа очередью.

**Практика.** Добавьте 1 и 2, извлеките один элемент, добавьте 3, извлеките всё. Порядок извлечения: 1, 2, 3. Повторите через два стека, записав единственный перенос для первых двух элементов.
