# Стеки

[← К разделу](../README.md)

## Последнее действие обслуживается первым

Стек — структура с доступом только к вершине. Добавление кладёт элемент сверху, извлечение снимает верхний, просмотр показывает его без удаления. Правило LIFO означает «последним пришёл — первым вышел».

Стопка тарелок — бытовая аналогия. В программных задачах стек удобен для вложенности, истории отмены и возврата к незавершённой работе. Для произвольного поиска внутри стека он не предназначен.

## Пример: скобки в формуле

Нужно проверить последовательность «([])». Читая открывающую скобку, кладём её в стек. Читая закрывающую, требуем соответствующую скобку на вершине и снимаем её.

1. После «(» стек содержит «(».
2. После «[» сверху «[», под ней «(».
3. Символ «]» соответствует вершине «[»: снимаем её.
4. Символ «)» соответствует оставшейся «(»: стек пуст.

В конце стек пуст, значит все открытия закрыты. Для «([)]» при третьем символе наверху «[», а пришла «)»: ответ отрицательный, хотя количество открытий и закрытий совпадает.

Корректность опирается на вложенность: первой должна закрываться последняя ещё не закрытая скобка. Стек хранит именно такие открытия в порядке вложения. Закрывающая скобка при пустом стеке сразу означает ошибку; непустой стек в конце — незавершённые открытия.

## Сложность и другие применения

Каждый из n символов добавляется или удаляется не более одного раза: O(n) времени. В худшем случае все символы открывающие, поэтому O(n) дополнительной памяти. Для одной разновидности скобок достаточно счётчика, но для разных видов нужен порядок.

Просмотр вершины и извлечение — O(1); добавление в стек на динамическом массиве амортизированно O(1). Стек вызовов при рекурсии использует ту же идею: последняя начатая функция завершается первой.

**Практика.** Проверьте «()[]», «(()» и «)(». Ответы: верно, неверно из-за остатка, неверно уже на первом символе. Затем составьте историю действий «ввести А, ввести Б, отменить»: после отмены должен остаться результат первого действия.

Запуск из корня репозитория с установленным .NET 10 SDK:

```powershell
dotnet run --project examples/AlgoTraining.csproj -- 02-linear-data-structures/05-stacks
```

Устройство проекта, смысл современных конструкций и общие команды описаны в [инструкции запуска](../../examples/README.md). В методических темах код демонстрирует учебный сценарий; в алгоритмических — реализацию и её применение.
